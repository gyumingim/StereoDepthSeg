# scan3d 로드맵 — 3D 스캐너와 실내 드론 둘 다 (2026-10-17 결정)

사용자 결정: **두 용도 모두** 한다. 같은 코드에 계속 붙이지 않고, 공통 부분과 용도별 부분을 나눈다.

**역할 분담 (2026-10-17 사용자 결정): 실시간 = 드론용, 녹화 = 스캐너용.**
- 실시간(드론): 폰에서 **ARCore** 위치 추적 + IMU 필터(수백 Hz 자세, 지연 보상) + ARCore Depth 또는 ToF 로 장애물. ARCore 가 후면 카메라를 잡으므로 두 렌즈 스테레오는 실시간에 안 씀. 지상 PC 는 지도·상태만.
- 녹화(스캐너): 두 렌즈(2+5, 필요 시 2+6) 녹화 → PC 에서 OpenVINS/SfM + FFS + TSDF 정밀 복원. 지금의 '실시간 스캔' 화면은 녹화가 잘 되는지 보는 **미리보기** 정도로만 유지.
- 공유: 녹화 형식, 지도 저장·재위치, 장애물 지도(ESDF), 웹 리플레이.

## 트랙 A — 3D 스캐너 (정밀 결과물, 오프라인 OK)
- 병목 = **깊이 노이즈** (기선 15.5 mm, 국소 벽 두께 약 11 cm). 위치는 충분히 정확 (SfM 표류 0.2 cm).
- 진행 중: 2+5/2+6 합치기, 여러 키프레임 일관성, 오프라인 FFS 품질, TSDF 가중.
- 다음 시험 (먼저 재 보기): **단안 깊이 모델 (Depth Anything 계열) 로 모양 + 스테레오·VIO 로 크기** — 기선 한계를 피할 수 있는지 녹화로 측정.
- 결과물: 정밀 복원(SfM) + 메시(.ply/.obj).

## 트랙 B — 실내 드론 (실시간·저지연·가벼움)
- 필요한 것: 끊기지 않는 위치 추적, 5~10 cm 장애물 지도(ESDF, 진행 중), 낮은 지연. 정밀 메시는 필요 없음.
- **구조 (결정):** 기체의 폰에서 ARCore VIO + IMU EKF(고속 자세·지연 보상) + ARCore Depth/ToF 장애물 → 지상 PC 에는 지도·상태만 (영상 전송 안 함). 지금 깊이(FFS)는 RTX 5080 의존이라 기체에 안 올림.
- 보완할 것: ARCore 자세 30 Hz·약 1 프레임 지연 → IMU 로 채우기, 추적 잃음·좌표 재정렬 감지 시 호버 안전장치, 프로펠러 진동 → 방진 마운트 필수.
- 먼저 잴 것 (폰): ARCore 자세 지연·떨림, Depth API 해상도·거리별 오차, 진동 조건에서 추적 유지.
- 실내 드론 프로젝트(indoor_drone 저장소: 폰 VIO 앱, ArUco, ESP32 계획)와 합칠 지점.

## 순서
1. 진행 중 작업 마무리 (깊이 노이즈, 지도 저장·ESDF) → 회귀 검증 → 커밋.
2. 폰을 쓸 수 있을 때: 축척 검증 + 실시간 전체 시험 (10 분).
3. 트랙 A: 단안 깊이 시험 (녹화로).
4. 트랙 B: 기체/지상 분담 구조 결정 → 폰 VIO 실측.
