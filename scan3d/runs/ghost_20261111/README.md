# ghost 2026-11-11 — TSDF 메시의 "유령 이중층" 줄이기

브랜치 `ghost-20261111` (kfonly a4f1325 위), 워크트리 `~/scanner/StereoDepthSeg-ghost`. 계산은 전부 노트북 (`remote_laptop.sh`), 창 안 띄움.
0–4 절은 **실행 전에 커밋** (사전 등록). 바꾸면 아래에 날짜·이유를 덧붙인다.

## 0. 문제
kfonly 6.1: 20261022_134550 A 메시의 보드 꼭짓점 9523 개 중 33.6 % 가 주 면에서 0.5 cm 넘게 떨어진 두 번째 층 (약 1.75 cm 아래).

## 1. 데이터 · 입력 (녹화 1 개 — 사용자 규칙)
- 녹화 20261022_134550, GT `imu_gt_spl_cal1022` (채점에만).
- 자세 = kfonly 노트북 A 의 kf_ba 자세 `A_poses_ba_134550.jsonl.gz` (sha256 2037d8ea…, BA 다시 안 돌림).
- 깊이 = `ghost_cache.py` (= scanA/scan_offline.py 복사 + 키프레임마다 TSDF 에 넣기 직전의 Z·σ·유효·색·자세를 npz 로 저장, 그 밖은 같음)
  `--compress --kf-step 1` FFS 960×540 8 회, **한 번만** 계산. 이 실행의 메시가 kfonly A 와 같은지 (이중층 비율 ±0.02) 로 캐시가 맞는지 먼저 확인.
- 변형은 `ghost_fuse.py` 에서 깊이 → 메시 단계만 바꿈 (같은 캐시, 같은 채점).

## 2. 가설 (싼 것부터) · 진단
- H1 패스 사이 자세 차이: 키프레임마다 보드 화소를 BA 자세로 월드에 올린 높이 중앙값 (`diag_kf.json` zw) 이 두 무리로 갈리면 → 자세 (또는 깊이) 가 패스마다 다름.
  GT 자세로 올린 높이 (zgt, 깊이 오차만) 와 비교해 자세 몫 / 깊이 몫을 가름.
- H2 FFS 깊이 치우침 (거리·가장자리): zgt 가 키프레임 거리 Z 에 따라 달라지는지.
- H3 TSDF 잘림이 층 간격보다 작음: 잘림 바닥 2.5 복셀 = 1.25 cm < 1.75 cm → 두 면이 서로 안 지움.
- H4 융합 전 다시점 일관성 검사 없음.

## 3. 변형 (`ghost_fuse.py` 머리말)
base (= A) · twide (잘림 2.5 cm, k 3) · cons (다시점 일관성, 이웃 8, 아무 때) · consx (다른 패스만 |dt| ≥ 3 s) · icp (프레임→모델 ICP) · icp_cons.
진단 결과를 본 뒤 변형을 더하면 여기 날짜와 함께 적고 같은 규칙으로 판정 (탐색 표시).

## 4. 판정 (사전 등록, base 대비, 녹화 1 개 1 회)
- 이중층 비율 (보드 꼭짓점 중 주 면에서 > 0.5 cm, `mesh_layers` 정의) ≤ base 의 **1/3**
- |dZ| p90 (융합에 들어간 보드 화소, GT 평면 깊이 대비 = scan_offline `pooled_absdZ_cm.p90` 정의) 가 base 보다 **+5 % 넘게 나쁘지 않음**
- 보드 덮임 (`mesh_board_cover_frac`) ≥ base 의 **90 %**
셋 다 → 통과. 통과가 여럿이면 이중층 비율이 가장 낮은 것 (같으면 단순한 것) 을 "최선" 으로. 녹화 1 개 = 추정.
같이 적음 (판정 밖): 주 층 RMS, 메시 보드 |z| p90 (GT 평면 대비), 융합 시간.
- 한계: 자세 자체를 바꾸는 변형 (icp) 은 |dZ| (GT 자세 기준 깊이) 를 바꾸지 않으므로 그 변형의 정확도는 메시 |z| p90 로도 봄.
