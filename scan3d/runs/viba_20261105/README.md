### 2.2 VI-BA (새것, `scan3d/viba/viba.py`, GTSAM 4.x 파이썬)
- 변수: 키프레임마다 IMU 자세 T_world_imu, 속도 v, IMU 치우침 (가속도·자이로); 점 (기준 BA 와 **같은 트랙·같은 관측·같은 초기 점**).
- 인자: (1) 재투영 (`GenericProjectionFactorCal3_S2`, body_P_sensor = T_imu_cam, Huber 1 px, σ 1 px, 내부값 Kr 고정 = 기준 BA 와 같음),
  (2) 연속 키프레임 사이 IMU 사전적분 (`CombinedImuFactor`, 치우침 랜덤워크 포함), (3) 게이지: 첫 키프레임 자세 사전 (위치 σ 1 mm, 회전 σ 0.05 rad,
  VIO 값 둘레), 첫 치우침 사전 (σ 가속도 0.1 m/s², 자이로 0.01 rad/s). **축척 자유** (Sim3 정렬 없음, VIO 축척을 받지 않음), 중력 방향은 IMU 가 정함.
- IMU: 녹화 `imu.csv` 원시 (uncalibrated 35/16, 값 0..2 = 라이브와 같음), 가속도를 자이로 시각에 보간 (= lp_replay/OvRunner).
  잡음 = c4f60 `kalibr_imu_chain.yaml` 값 그대로 (가속도 1e-2 / 1e-3, 자이로 1e-3 / 1e-4), 중력 9.80 (estimator yaml), VIO 월드 −z 방향 (부호는 정지 구간으로 확인).
- 카메라–IMU 외부값 · 시간차 = c4f60 `kalibr_imucam_chain.yaml` (T_imu_cam, timeshift_cam_imu 2.172 ms; t_imu = t_cam + shift). H 는 hs222 설정
  (외부값·시간차 같음, 내부값만 다름). 키프레임 IMU 시각 = 프레임 t_ns + shift.
- 초기값 = VIO: 카메라 자세 = VIO 키프레임 카메라 자세 (기준 BA 초기값과 같음), IMU 자세 = T_wc · T_ci, v · 치우침 = 그 시각 VIO 상태.
- 풀이: Levenberg–Marquardt (GTSAM, 최대 100 회). 결과 카메라 자세 = T_world_imu · T_imu_cam 을 그대로 씀.
- 변형 (사전 등록, 민감도): `viba_on` = 외부값·시간차를 yaml 대신 VIO 온라인 보정 마지막 값으로.
- 양성 대조 (사전 등록): 초기값 축척을 ×1.03 으로 늘림 (첫 키프레임 둘레 위치·점, 속도 ×1.03) → VI-BA 가 같은 k 로 돌아와야 함
  (13 개 중 ≥ 10 개에서 |k(×1.03 시작) − k(보통 시작)| ≤ 0.3 %p). 못 돌아오면 "VI-BA 축척이 IMU 로 정해지지 않음" → 1차 판정 무효.
- 물리 시험 (먼저): VIO 상태 그대로 IMU 인자 잔차 크기, 중력 부호, 정지 구간 |a| ≈ g.

## 3. 채점 (같은 키프레임, 같은 스크립트, 기준 BA · VI-BA · (참고) VIO 키프레임에 같게)
- M1 축척 k (%), + = 길다: GT 짝 = 같은 t_ns 의 GT 행 (< 2 ms, H 는 < 1 ms; ok; |p| < 1.2 m), 위치 = 카메라 중심.
  - k_fwd = 정방향 Umeyama (자세 → GT) 축척 s 로 1/s − 1 (scalehunt R2 와 같은 식) — **주 자**.
  - k_pair = 1 s 떨어진 키프레임 짝 (GT 거리 > 10 cm) 의 |dP| / |dGT| 중앙값 − 1 (정렬 없음, 검증자 vsh 자와 같은 식).
  - k_rev (역방향) 참고.
- M2 보드 모서리 자 (`corner_eval.py`, GT 자세 안 씀, 보드 칸 크기만): 다시점 축척 오차 %, 2 시점 모양 RMS 중앙 / p90 mm.
  165506 은 반드시; H 는 돌아가는 녹화만 (안 되면 적음).
- M3 보드 깊이 (`scan_offline.py` 960×540, FFS·TSDF 5 mm, 축척 그대로 = 실제 스캐너 상황, 오라클 축척 없음): 전체 화소 dZ 평균 / 중앙 / p10 / p90 cm,
  |dZ| p90, 메시 보드 z 중앙 / RMS. H 는 `--compress --kf-step 1` (scanA more 와 같음).
- 지킴 지표: 재투영 오차 중앙 px, ATE (SE3, 키프레임) cm.

## 4. 판정 (13 녹화)
- 1차 (M1): VI-BA 가 축척을 0 쪽으로 옮겼다 = 녹화별 |k_fwd| 중앙값이 기준 BA 보다 **≥ 0.5 %p 줄고** **13 개 중 ≥ 9 개**에서 |k_fwd| 가 줄어듦.
  k_pair 도 같은 방향인지 적음 (다르면 "자에 따라 다름"). 양성 대조 실패면 판정 무효.
- 165506 하나: |k_fwd| ≤ 1 % 이고 모서리 자 |축척| ≤ 1 % 이면 "165506 고쳐짐 (녹화 1 개, 추정)".
- M3: 녹화별 |전체 화소 dZ 평균| 중앙값이 20 % 이상 줄고 (p90 − p10) 폭 중앙값이 20 % 넘게 늘지 않으면 "보드 깊이 좋아짐".
- 지킴: VI-BA 재투영 중앙 > 기준 + 0.1 px 인 녹화는 따로 표시 (시각 일관성을 버리고 IMU 에 끌려감).
- 그 밖은 "잡음 수준" 또는 "나빠짐". 숫자를 맞추려고 잡음 값·외부값을 바꾸지 않는다 (바꾼 변형은 탐색으로만 표시).
