## 2. 조건 (`conds.json`, 섞인 변수는 각 줄의 why)
B60 (기준선), FNN (xfopt 최종, 문 포함), L (= X1Lt3: LG 1k + 시차 3°, 문 없음; FLG = L 위에 sim 문 inl 60 · ratio 0.6 · rp 2),
Lc (LG 점수 문턱 filter_threshold 0.1 → 0.03), Lp (가지치기 항상 = 폰과 같음), Lpd (가지치기 + 조기 종료 depth 0.95),
L512 (점 512), LT (이전 KF 삼각측량은 NN, LG 는 루프 후보에만), Lm (PnP 최소 인라이어 25 → 15), Lbud (512 + NN 삼각 + 가지치기 + 조기 종료 = 폰 예산 조합).
서버 · 다리 수준이 다른 것만 실행으로 돌리고, 문 (gate) · 후보 수 · KF 표본은 `sim.py` 로 오프라인 재적용 (xfopt 와 같은 방식; 재현기 = 실제 확인 후 사용).
- sim 추가: max_cand (BoW 순 앞 N 후보만, 정확), kf_every (마지막 시도 뒤 kf_every 초 안의 KF 는 후보 검사 안 함; 삼각측량은 그대로 → 근사, 폰 시간 추정용).
- Lm 위의 inl ≥ 25 는 L 과 정확히 같지 않다 (A 방향이 15–24 인라이어로 성공하면 B 방향을 안 봄) → 근사로 표시.

## 3. 목적함수 · 선택 규칙 (개발 15칸, 사전)
- J = good − 100 · max(0, 틀림3° − B60) − 20 · max(0, 틀림2.5° − B60)  (xfopt J 와 같은 형태, B60 = 새 렌즈 개발값).
- **바뀐 것 (기록)**: 문 검색을 순차 대신 **작은 격자 전체** (inl {0, 40, 60} × ratio {0, 0.3, 0.45, 0.6} × cells {0, 10} × rp {3, 2} × yaw {10, 3})
  로 한다. 이유: 순차 검색은 먼저 고른 문이 나중 문과 겹쳐 지나치게 조인다 (위 0절). 격자는 조건 (서버 설정) 마다 같다.
- 통과: 틀림3° ≤ B60 그리고 틀림2.5° ≤ B60 (xfopt 규칙). 통과한 것 중 J 최대. **J 가 최대값의 1 % 안 (≈ good 차 1 %)** 이면
  (1) 문이 느슨한 것 (ratio 낮음 → inl 낮음), (2) 폰 비용 낮은 것 순으로 고른다. 손 루프 (SEEN) 루프 수는 표에 적기만 하고 선택에 쓰지 않는다.
- 폰 예산 (측정은 나중, 추정만): 점 512 vs 1024, 후보 1–3 (max_cand), KF 표본 (kf_every 0 / 1 s, consist_kf 3 / 6), 조기 종료 · 가지치기.
  PC 시간은 상대 비교만 (`lg_bench.py`, GPU · CPU 단독, 같은 KF 쌍). 폰 ms 는 기존 측정 (LG N=512 66 ms, 1024 195 ms) 비율로 **추정** 표시.
- 최종 FLG' = 위 규칙의 1위 (서버 설정 + 문 + 후보 수 + 표본). 개발 표에 B60 · FNN · FLG · FLG' (틀린 루프 · 2.5° · good · 손 루프 수 · 지도 ATE) 를 적는다.
  지도 ATE 는 실제 실행에서만 (sim 의 문 변경은 지도 ATE 를 바꾸므로, FLG' 의 문이 실행 조건과 다르면 FLG' 실행을 따로 한 번 돌린다 — 개발 칸만).

## 4. 최종 판정 (새 60 fps 실시간 GT 녹화, 독립 데이터, 한 번) — 지금 고정
- 새 녹화: 사용자가 새로 찍을 60 fps 실시간 GT 녹화 (HS 보드 GT) + **흰 벽 손 루프 녹화 ≥ 2개** (없으면 R2 "해당 없음" 이 아니라 "판정 불가 → 보류").
  B60 · FNN · FLG' 를 같은 빌드 · 같은 렌즈 (그 녹화의 초점에 맞는 **직접 잰** 렌즈) 로 칸당 1회. 조건 목록 · 판정 스크립트는 녹화를 열기 전에 커밋, 채점 뒤 고치지 않는다.
- GT 품질 문턱은 보드마다 녹화 전에 정한다 (HS 6×6 보드: 모서리 ≥ 12; 다른 보드는 그 보드 GT 잡음 p99 로 미리 정함). 중복 칸은 실행 전체 로그로 판정.
- R1–R4 는 xfopt PLAN 4 그대로 (R1 틀림 ≤ B60, R2 흰 벽에서 B60 0 개 녹화에 후보 ≥ 1, R3 지도 ATE 짝 차 중앙 ≤ +0.02 cm, R4 폰 키프레임 총 시간 p50 ≤ 150 ms 2회).
- **FLG' 가 FNN 대신 채택되려면 모두 만족**: (1) FLG' 가 R1–R4 통과, (2) 틀림 3° ≤ FNN, (3) 틀림 2.5° ≤ FNN (LG 의 "정밀" 장점 확인),
  (4) 흰 벽 루프를 받은 녹화 수 ≥ FNN, (5) 지도 ATE 짝 차 (FLG' − FNN) 중앙 ≤ +0.02 cm. 하나라도 못 하면 FNN (싸고 단순한 쪽).
  둘 다 R1–R4 를 못 넘으면 채택 없음 (B60 유지). 2.0° 대역 개수 · 에지당 비율은 보고만.
