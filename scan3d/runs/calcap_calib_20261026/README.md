## 축 정의 (roll / pitch / yaw)
카메라 좌표 (OpenCV): x 오른쪽, y 아래, z 앞 (광축). 보드→카메라 회전 **R = Ry(yaw) · Rx(pitch) · Rz(roll)** (내재 Y–X′–Z″ 순서: 먼저 카메라 y 축으로 yaw, 그다음 새 x 축으로 pitch, 마지막 보드 법선으로 roll).
0,0,0 = 보드가 카메라를 정면으로 보고 보드 x = 화면 오른쪽, 보드 y = 화면 아래. n = 보드 법선 (R 의 3번째 열, n_z > 0 으로 맞춤).
- **yaw** = atan2(n_x, n_z), **+ = 보드 오른쪽 가장자리가 카메라 쪽으로** 다가옴 (세로축 회전).
- **pitch** = asin(−n_y), **+ = 보드 위 가장자리가 카메라 쪽으로** 다가옴 (가로축 회전).
- **roll** = 나머지 회전 (Ry·Rx)ᵀ·R 의 z 축 각, **+ = 화면에서 시계 방향** (x 오른쪽 → y 아래 쪽으로).
- slots.py 이름과 관계: turn = atan2(n_x, |n_z|) ≈ yaw (같은 부호), lean = atan2(n_y, |n_z|) ≈ −pitch (반대 부호). 예: E40-T-lean− 는 pitch +45°.
- 부록 (합친 각, 법선과 광축 사이 각) 사진 수: 0–10° 36, 10–20 8, 20–30 24, 30–40 48, 40–50 8, 50–60 8.
