# hybrid 11-07 — FFS 깊이 기본 + FFS 실패한 곳만 VGGT 깊이 (사전 등록)

작성 2026-11-06 (결과 보기 전, 이 파일을 먼저 커밋). 브랜치 `hybrid-20261107` (mvggt-20261106 47c99ae 에서).

## 1. 질문
mvggt (README 7) 결과: B0 (FFS) 는 깊이 없는 키프레임이 많고 (FFS 짝 실패), VGGT 깊이 (V2) 는 꼬리는 줄지만 표면이 거칠다 (메시 RMS 1.3–11 배).
→ **FFS 를 기본으로 쓰고, FFS 가 실패한 곳만 VGGT 깊이로 메우면** 표면은 FFS 처럼 유지하면서 빈 키프레임·꼬리를 줄일 수 있나?

## 2. 변형 (모두 BA 자세, 같은 TSDF·같은 채점 코드 `scan3d/hybrid/hy_offline.py` = mv_offline.py 복사 + 캐시·메우기)
| 이름 | 깊이 |
|---|---|
| B0 | FFS 만 (mvggt 결과 재사용, 비교 기준) |
| B0r / B0c | B0 재현 (FFS 다시 계산 + 깊이 캐시 저장) / 캐시에서 B0 다시 융합 — 재현 관문 |
| V2 | VGGT 깊이만 (mvggt 결과 재사용) |
| **H1** | FFS 깊이 없는 키프레임만 V2 깊이 (조각 축척 그대로). 134204 VGGT 조각 6 (축척 0.145 실패, mvggt 7.2) 은 쓰지 않음 |
| **H2** | H1 과 같되, 메우는 키프레임마다 V2 깊이 × 비율. 비율 = **같은 VGGT 조각** 안에서 가장 가까운 FFS 키프레임 최대 4 장의 (FFS / V2) 중앙값의 중앙값. FFS 키프레임마다 비율 = 영상 전체에서 둘 다 유효한 화소의 Z_ffs / Z_vggt 중앙값 (≥ 2000 화소, GT·보드 정보 안 씀). 같은 조각에 FFS 키프레임이 없으면 메우지 않음. 조각 제외 없음 (비율로 고침) |
| **H3** | H2 + FFS 키프레임 안 화소 메우기: FFS 무효 화소 (motion_stereo combine_motion 의 valid=0, 낮은 신뢰·불일치 포함) 이면서 VGGT 마스크 (신뢰 상위 50 %) 인 곳을 V2 × 그 키프레임 자신의 비율로 채움 |

- VGGT 화소 sigma = 0.003 + 0.01 Z² (V2 와 같음), FFS 화소는 FFS sigma 그대로.
- 오라클 축척 (`--free-scale`): 자세 이동 × s, VGGT 깊이도 × s (V2 와 같음), FFS 캐시는 오라클 자세로 따로 계산.
- 조각 번호 = raw_vggt.npz 의 chunk/fidx 에서 각 키프레임이 처음 나온 조각 (mv_align V2 축척과 같은 규칙).
- VGGT·BA 는 다시 돌리지 않음 (mvggt rec/<id>/al/V2_depth.npz, raw_vggt.npz, poses_ba.jsonl.gz 를 읽기만).

## 3. 실행 (`hy_rec.sh ID`, 녹화 165506 · 20261022_134204 · 20261020_222747, 변형마다 1 회)
축척 native · oracle 각각: B0r (FFS + 캐시) → B0c, H1, H2, H3 (전체 키프레임 = mvggt 와 같은 kf_subset) →
겹침 집합 (mvggt overlapV_{native,fs}.txt = B0·V1·V2 모두 평가된 kf) 에서 B0c_ov, H3_ov 다시 융합.
겹침 집합의 키프레임은 모두 FFS 깊이가 있으므로 H1·H2 는 겹침에서 B0 와 같다 (만들어진 대로) — 165506 에서 H1_ov 로 한 번 확인만.

**재현 관문**: B0r 의 전체 |dZ| p90 · 메시 RMS 가 mvggt B0 와 0.05 cm 이내, B0c 가 B0r 와 같아야 (캐시 정확) 결과를 쓴다.

## 4. 지표 (mvggt 와 같은 코드, cm)
- 전체 화소 |dZ| 중앙 · p90, 키프레임별 |dZ| 중앙의 중앙값 · p90 의 중앙값
- 보드 메시 RMS, 덮임 (보드 1 cm 칸 중 3 cm 안에 메시 점 있는 비율)
- 키프레임 |치우침| > 1 cm 비율 (평가된 kf 중, mvggt 와 같음)
- **실패 kf 비율 (새, 판정에 씀)**: 보드가 보이는 키프레임 (GT 자세로 보드 화소 > 200) 중 깊이 없음 · 평가 안 됨 (보드 위 유효 화소 ≤ 200) · |치우침| > 1 cm 인 것의 비율
- 참고 (판정 안 씀): 메운 키프레임만의 키프레임별 통계 (H vs V2, 같은 kf), 메운 kf 수, 화소 메우기 수

## 5. 판정 규칙 (사전 등록)
녹화마다, **오라클 축척 · 전체 키프레임** 에서 변형 H 가 다음을 모두 만족하면 그 녹화 "통과":
1. 덮임 ≥ B0 + 0.01 **또는** 실패 kf 비율 ≤ B0 × 0.8
2. 메시 RMS ≤ B0 × 1.2
3. 키프레임별 |dZ| 중앙의 중앙값 ≤ B0 × 1.1

H 가 녹화 3 개 중 **2 개 이상 통과** → "추천 후보" (다음 단계: 실시간 경로 적용 검토). 아니면 "채택 안 함".
B0 값은 이 실행의 B0c (캐시 재융합, 관문 통과 시 mvggt B0 와 같음) 를 쓴다. native 축척·겹침 집합 결과는 보고만 한다.
