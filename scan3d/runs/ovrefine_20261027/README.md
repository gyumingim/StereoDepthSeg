  - 창 = 최근 N 스냅샷. 새 스냅샷마다 창 전체를 **OpenVINS 값으로 새로 초기화**해서 한 번 푼다 (이전 결과를 이어 쓰지 않음 → 혼자 떠내려갈 상태 · 재시작 상태가 없음).
    요인: VINS `IntegrationBase` / `IMUFactor` (잡음 = OpenVINS 밀도 × √(IMU rate)), VINS `ProjectionFactor` (sqrt_info = fx / 1 px = OpenVINS up_msckf_sigma_px, Huber 1),
    새 `PriorFactor` (첫 상태 15 차원, OpenVINS 공분산 × prior_scale). VINS 초기화 · 특징 관리 · 주변화 · 자체 추적은 안 씀. Ceres DENSE_SCHUR + DOGLEG, 10 반복, 1 스레드 (결정적).
  - 출력 = 포즈 줄 `"ref"` 객체 (`valid`, `p`, `q`, `v`, `T_world_cam0`, `n_win`, `n_ok`, `n_rej`) 만. 받아들인 창의 보정 ΔT = T_ref T_ov⁻¹ 를 다음 스냅샷까지 적용.
  - 안전장치 (창 버림 → OpenVINS 그대로): 해 사용 불가, 비용 증가, 비용/잔차 > 25, 트랙 < 20, 위치 차 > 5 cm, 회전 차 > 2°, 비유한값, IMU 없음. 이유별 개수 로그.
    OpenVINS 재초기화 · 추적 잃음 · 스냅샷 간격 > 0.5 s → 창 비움. `--swba` · `--recover` 와 같이 켜면 거부 (VINS 전역값 공유).
