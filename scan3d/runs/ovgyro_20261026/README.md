| `gyro_klt=5` (**추천**) | 3 + 안전장치: 이동 부분은 직전 프레임 health OK(또는 health 꺼짐)·|v| ≤ 3 m/s 일 때만; 점마다 이동 부분 > 60 px 면 회전만 |
| `--klt-stats 1` | 출력만: 포즈 줄 `"klt":[입력, LK 성공, 남은 점, 예측 이동 px, 재시도, 재시도 성공, 회전 있음, |결과−시작|, |결과−이전|, 예측 x, y, 흐름 x, y]` + 끝에 stderr 요약 (안전장치 걸린 점·프레임 수 포함) |
