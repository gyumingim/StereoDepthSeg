## 옵션 (전부 기본 꺼짐)
| 옵션 | 내용 |
|---|---|
| `--ovopt gyro_klt=1` | 회전만: 프레임 사이 자이로 적분 (바이어스는 초기화 뒤 빼기, R_ItoC, t_d) → R_C1C0 로 시작점 이동 |
| `gyro_klt=2` | 1 + LK 실패 점을 원래 시작점에서 한 번 더 |
| `gyro_klt=3` (**추천**) | 1 + 초기화 뒤 이동: 상태 속도 × 프레임 간격, 깊이 = 그 점의 SLAM 점(같은 id) 아니면 SLAM 점 역깊이 중앙값 |
| `gyro_klt=4` | 3 + 2 의 재시도 |
| `--klt-stats 1` | 출력만: 포즈 줄 `"klt":[입력, LK 성공, 남은 점, 예측 이동 px, 재시도, 재시도 성공, 회전 있음, |결과−시작|, |결과−이전|, 예측 x, y, 흐름 x, y]` + 끝에 stderr 요약 |
- 앱: 기존 intent `ov_opt` 문자열에 `gyro_klt=3` 를 넣으면 됨 (앱 코드 변경 없음, APK 안 만듦). 묶음 예: `--ovopt all_exact,ekf_gemm,qr_compress,ekf_chol,gyro_klt=3` (`--profile rec20261025` 뒤에 명시하면 명시값이 이김).
- 파일: `ov_bridge/ovpatch/gyro_klt.h`(새), `ovpatch/TrackKLT.cpp`, `ovpatch/VioManager.cpp`, `ovpatch/ovopt.h/.cpp`, `main.cpp`.
- PC 라이브러리 빌드(OV_FULL_SOURCE 아님)는 gyro_klt 를 거부 (다른 ovopt 옵션과 같음). `OV_GK_DEBUG` 환경변수 = 프레임마다 디버그 줄(stderr)만.
