## 결론 (먼저)
- **FNN (XFeat NN 1k, 640, 삼각측량 시차 3° + XFeat 전용 문) 이 PC 규칙 R1–R3 를 통과했다. FLG (LighterGlue) 는 R2 (흰 벽) 에서 탈락.**
- **R4 (폰 시간) 는 못 쟀다** (adb 기기 없음) → PLAN 대로 판정 = **"PC 통과, 폰 보류"**, 아직 채택 아님. 폰 앱 통합 (C++ XFeat) 도 아직 안 함 (아래 RESUME).
- 무엇이 효과였나 (개발용에서만 조정): 삼각측량 시차 1° → 3°, XFeat 경로 문 (인라이어/매칭 ≥ 0.3, 인라이어가 8×6 격자 ≥ 10칸, VIO 중력 대비 roll/pitch ≤ 2°, yaw 보정 ≤ 3°).
  개발에서 3°/2.5° 틀림을 가장 많이 줄인 것은 인라이어 비율 문과 rp 문 (3° → 2°) 이었다 (dev_eval.json 순차 기록).
