결론 먼저

  1. 범인은 "저각 짝"이다. 앞으로 걸을 때 만든 짝(광축-기선 각 10–30°, 에피폴이 화면 안, 부분 정류: low, relax)의 시차 오차는 강건 SD 1.0–1.4 px. 옆으로 움직인 짝(base, wide)은 0.16–0.21 px. 그런데 저각 짝은 ROI 화소가 기선에서 28–35°밖에 안 떨어져 있어서(25° 차단선 바로 옆) px 하나가 깊이 2–4 cm 가 된다. 오차가 크고, 그 오차를 키우는 배율도 크다.
  2. 캐비닛 앞면은 짝 18 개가 전부 저각 짝이다(각 중앙 11°). 같은 kf 의 low 짝과 relax 짝이 서로 반대로 ±4–9 cm 벌어진다(|dev| 중앙 5.7 cm). 그래서 장 사이 SD 가 2.7 cm 다. 짝을 빼는 규칙으로는 못 고친다. 빼면 캐비닛 깊이가 통째로 없어진다.
  3. 벽 538: relax 짝은 평균 −1.50 cm(n 10, 더 멀리 찍힘). 나머지 짝은 +0.29 cm(n 57). 다만 같은 kf 의 base 짝도 −1.9 cm(n 2)라서 짝 탓이라기보다 kf 탓(주로 kf 649, 642)으로 보인다. 같은 kf 안에서 relax 짝과 다른 짝의 차이(dev)는 +0.40 cm 로 작다.
  4. 바닥 3205: 저각 짝이 거의 없다. 바깥값이 큰 쪽은 VIO 포즈로 만든 wide 짝(wide_vio): SD 1.18 cm, BA 포즈 wide 짝은 0.86 cm.
  5. 스케일인가, px 인가: 짝 255 개 전체(ROI 별 중앙값을 뺀 뒤; 가운데 기선 구간에 저각 짝이 섞여 있음)에서, 기선이 길어져도 깊이비 SD 가 거의 그대로(0.38 / 0.61 / 0.45 %)이고, px 로 환산한 SD 는 2 배가 된다(0.14 → 0.28 px). 그러니 남은 오차는 "고정 px"(FFS 잡음·회전 오차)보다 "깊이에 비례하는 %"(기선 길이·포즈 스케일 오차) 쪽에 가깝다. 회귀 기울기 log B = −0.40 ± 0.16 으로, 두 모형(0 과 −1) 사이에 있다 = 섞여 있음. 참고로 두 BA(ba_partners vs ba_partners2)가 같은 짝의 기선 길이를 ±1 % 다르게 본다(5–95 % 0.986–1.012). 1.7 m 에서 ±1.7 cm 로, 관측된 어긋남과 같은 크기다. 이것이 원인이라는 것은 추정이다.
  6. 규칙 시험: 세 ROI 를 다 해치지 않으면서 뚜렷이 좋아지는 규칙은 없다. 가장 나은 것은 no_wide_vio(VIO 포즈 wide 짝 빼기)다. 바닥 b SD 0.79 → 0.64, c 0.75 → 0.61 로 좋아지고, 벽은 b SD 0.96 → 1.02(강건 SD 0.77 → 0.55), c 0.85 → 0.98 로 섞여 있고, 캐비닛은 그대로다. 화소는 99.0 % 남는다. no_relax 는 벽을 0.96 → 0.80 으로 좋게 하지만 캐비닛을 1.78 → 2.51 로 나쁘게 하고 화소를 7.9 % 잃는다. BA2 기선비로 다시 맞추기(rescale_ba2_pair)는 벽·바닥을 나쁘게 한다. BA2 가 더 맞다는 근거가 없다.
  7. 판정: 이 규칙들로 다시 융합하고 재학습하는 것은 NO-GO. 저각 짝은 필터가 아니라 녹화(옆걸음)로 해결할 문제다. wide_vio 짝 294 개를 BA 포즈로 다시 계산해 보는 것(BA 에 그 프레임 넣기 + FFS 재실행)은 다음 후보로 남긴다(효과는 추정).
