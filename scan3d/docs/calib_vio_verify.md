## 2. 1 ms 적분 수정 — 맞음

- `imu_on_grid` (train_imu.py:69-77): 표본 k 를 `grid[k] + DT/2` (DT = 1/500 s → 1 ms) 에서, IMU 시각 `t_imu + dt` 축으로 보간.
  적분 (`integrate_all`, :266-287) 은 표본 k 가 구간 [k, k+1] 을 몰고감 (R_{k+1} = R_k·exp(w_k DT)) → 중점 규칙이 맞다.
- `batch_sync.py:103` 의 `ts = START + k/HZ + 0.5/HZ − dt` 와 같은 관례 (dt 를 맞춘 쪽과 일치).
- `CACHE_VERSION = 2` 로 올려 옛 캐시를 안 씀. 합성 시험 `apply_test.json`: 늦음 1.0 ms → −0.0 ms, 회전 오차 0.19° → 0.0008°.
- 아주 작은 남은 점: 가속도는 구간 시작 자세 R_k 와 중점 표본 f_k 를 곱함 (2차 오차, 1 rad/s 에서 약 1 mrad). 무시할 수준.
