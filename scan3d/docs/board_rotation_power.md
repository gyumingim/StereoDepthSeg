# 보드 회전 시험 — 검출력 시험 (가짜 보드 y 편향 주입, 2026-10-22 저녁, 새 녹화 없음)

코드: imu_learn/board_rotation_power.py → runs/board_rotation/power.json (made 시각·입력 기록).
같은 지표: board_rotation.py 의 짝맞춤 (ate_floor.match), Sim3 (umeyama), L30 (ate_floor.lowpass, 30 s 이동평균), 같은 u_g.
대상: 무너지지 않은 실행만 — 134204 o0/o1/o2 (회전), 134550 o0/o1 (대조).

## 결론 (먼저)
1. **r 규칙 (r > 1.5 → GT, r < 0.667 → VIO) 으로는 보드 y 0.3 cm GT 편향을 못 잡는다.** 134204 의 깨끗한 실행 (o1, o2) 에
   "지표에 0.3 cm 로 보이는" 보드 y 편향을 넣어도 r 은 0.08–0.50 으로 계속 "VIO 쪽" 이다 (0.4 cm 를 넣어도 최대 0.74). 위아래 0.6 cm 가 몫을 눌러서다.
2. **실제 느린 편향의 약 1/3 만 지표에 남는다.** RMS 0.3 cm 의 느린 편향 (주기 40–120 s 사인, 직선 표류) 을 GT 에 넣으면 Sim3 + L30 뒤 보드 y 에 남는 양은
   **0.06–0.22 cm (중앙 0.10)**. 주기 40 s 는 30 s 이동평균이 약 1/3 로 줄이고, 녹화 길이 (60 s) 보다 긴 주기는 상당 부분이 Sim3 의 이동·회전에 흡수된다.
3. **축별 RMS (cm) 로는 잡을 수 있다 (가장자리).** 134204 공통 성분 (시작 위치 3 개 평균) 의 보드 y L30 RMS 는 **0.14 cm**.
   "지표에 0.3 cm 로 보이는" 편향을 넣으면 같은 값이 **0.19–0.43 cm** (모양·위상 14 개 중 최소 0.19) 가 된다 → 이 크기의 보드 y 편향은 **134204 에서는 가능성이 낮다 (가장자리, 녹화 1 개)**.
   "지표에 0.2 cm" 는 0.10–0.33 이라 **배제 못 함**. 실제 RMS 0.3 cm 편향 (지표에는 약 0.1 cm) 도 **배제 못 함**.
4. 대조 녹화에서는 보드 y = 위아래라 r 이 넣은 크기와 상관없이 0.96–1.01 → 대조는 이 질문에 정보가 없다.
5. 옛 바닥 "30 s 보다 긴 0.2–0.4 cm" 는 같은 방식 (Sim3 뒤 L30) 으로 잰 값이라, 비교할 크기는 아래 **"지표 기준 (cal)"** 행이다.

## 방법
- 편향 b(t) 를 GT 위치의 보드 y 성분에 더함 (GT 시각 기준이라 시작 위치 o0–o2 에 같은 편향). 그 뒤 Sim3 를 다시 맞추고 L30 을 다시 계산.
- 모양 14 개: 사인 A·√2·sin(2πt/T + φ), T = 40 / 60 / 120 s, φ = 0 / 90 / 180 / 270°; 직선 표류 ±A·√3·(2t/T_rec − 1).
- 크기 두 가지:
  - **raw**: 넣은 편향 자체의 RMS = A (0.2 / 0.3 / 0.4 cm).
  - **cal (지표 기준)**: 모양·실행마다 배율을 맞춰, 편향만 따로 Sim3 + L30 을 거친 뒤 보드 y RMS 가 A 가 되게 함 ("지표에 A cm 로 보이는 편향").
- 이미 있는 오차와 벡터로 더해지므로 위상에 따라 커지기도 작아지기도 한다 (그래서 최소·중앙·최대를 적음).

## 판정 기준 제안 (다음 녹화, docs/board_rotation_plan2.md 에 반영)
근거: 134204 깨끗한 실행의 보드 y 바닥 0.10–0.17 cm (공통 0.14), cal 0.3 주입 최소 0.18–0.25 (공통 0.19), cal 0.2 주입 최소 0.10–0.16.
- **보드 축 GT 편향 (지표 기준 ≥ 0.3 cm) 배제**: 회전 녹화 **모두**에서 공통 성분 보드 y L30 RMS < **0.15 cm**, 그리고 그 녹화에 cal 0.3 을 넣은 양성 대조의 최소값이 0.18 cm 이상 (= 이 녹화로 잡을 수 있음을 확인).
- **보드 축 GT 쪽**: 회전 녹화 **모두**에서 공통 성분 보드 y ≥ **0.25 cm** 이고, 대조 녹화의 보드 y 와 크기가 비슷 (0.5–2 배).
- 0.15–0.25 cm 또는 녹화끼리 엇갈림 → **미판정**.
- r 은 보조로만 적는다 (판정에 안 씀). 값은 녹화 1 개 · 실행 3 개에서 정한 것이라 거칠다 (추정).
- 한계: 실제 RMS 0.3 cm 의 느린 편향은 지표에 약 0.1 cm 로만 남아 이 설계 (60 s, Sim3, L30) 로는 못 잡는다. 이 기준이 답하는 질문은
  "옛 바닥처럼 **지표에 0.2–0.4 cm 로 보이는** 성분이 보드 축을 따르나" 이다.
