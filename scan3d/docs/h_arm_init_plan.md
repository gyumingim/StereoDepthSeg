질문: Hw15m05 (`--still-hold 1.5:0.05:0.05:m0.5`) 는 고친 3' (최대 GT 속도만) 로만 통과했고, F_214138_o0 에서 시작 정지 전체
(0.6–18.67 s, 초기화 18.82 s 직전까지) 를 붙잡았다 (docs/h_tune_verify.md). **붙잡기를 OpenVINS 초기화 뒤에만 켜면
(지연 0 / 3 / 10 s) 원래 사전 등록 기준을 18 묶음 모두 지키나?**

## 판정 (원래 사전 등록 그대로, z2_regression_plan.md + h_tune_plan 의 원래 3')
묶음 = F·O 는 녹화마다, T 는 녹화 × S. 반복 3 (시작 위치).
1. ATE 중앙값 ≤ max(base × 1.10, base + 0.2 cm). 2. 새 무너짐 0. 3. 헛 통과 0 (z2_regress.analyse_one 그대로).
3'. 붙잡은 구간 GT 속도 (±0.1 s 중앙차분, z2_regress.gt_speed): 묶음별 **> 2 cm/s 표본 비율 ≤ 0.5 % 그리고 최대 ≤ 3 cm/s (둘 다)**.
   - 붙잡은 프레임은 있는데 GT 표본이 0 → "시험 안 됨" (통과 아님). 붙잡기 0 → 해당 없음.
- 변형 통과 = 18 묶음 모두 1·2·3·3' 통과 (시험 안 됨이 있으면 "통과 아님 — 시험 안 됨 포함" 으로 적음) + 내려놓기 고침.
- 보조 (판정에 안 씀): 고친 3' (최대 ≤ 3 cm/s 만) 결과, 짝 한도 넘은 짝, 붙잡은 구간 |gyro|.
- 결과를 본 뒤 기준을 바꾸면 "사전 등록 규칙 실패" 로 표시. 녹화가 적고 같은 방·같은 손 → 모든 결론은 **추정**.
