1. 목표

폰 센서(IMU)만으로 위치를 계산하면 점점 틀어집니다. 센서가 아주 조금씩 틀리기 때문입니다.

목표: 센서가 어떻게 틀리는지 배워서 미리 고쳐 주기.

초록 = 실제로 움직인 길, 빨강 = 센서로 계산한 길

2. 재료: 영상 + 센서

폰을 들고 보정판(체크무늬 종이) 앞에서 움직이며 녹화합니다. 두 가지가 동시에 기록됩니다.

📷 카메라 영상 (1초에 60장) · 〰 센서 값 (1초에 500개)

3. 정답 만들기: 보정판이 "자" 역할

보정판의 크기와 무늬를 알고 있어서, 사진 한 장만 보면 폰이 판에서 어디에, 어떤 각도로 있는지 계산됩니다.

사진마다 하나씩 → 1초에 60개의 정답 점(파란 점)이 생깁니다.

4. 시계 맞추기

센서를 시간 이동

카메라와 센서가 같은 순간을 가리키게 맞춥니다. 영상으로 계산한 회전(파랑)과 자이로 센서의 회전(주황)이 딱 겹치는 위치를 찾습니다. 슬라이더를 움직여 보세요.

실제 측정: 둘 사이는 1~5 ms 차이 → 거의 정확히 맞음

5. 센서로 길 그리기

센서 값을 조금씩 더해 가며 길을 그립니다 (돌았다 → 밀렸다 → 빨라졌다 → 이만큼 왔다). 계산 공식은 정확한데, 센서 값이 살짝 틀려서 정답 점(파랑)에서 점점 멀어집니다.

6. 3초씩 잘라서 채점

긴 녹화를 3초 조각으로 자르고, 조각마다 "센서로 그린 길"과 "정답 점"의 거리(빨간 선)를 잽니다. 이 거리들의 크기가 점수(오차)입니다. 작을수록 좋습니다.

7. 손잡이 돌리기 (직접 해 보세요)

센서 기본 오차 (바이어스) 센서 배율 (축척)

오차:

센서를 고치는 손잡이가 있다고 생각하세요. 손잡이를 돌려 빨간 길이 파란 점에 붙게 만들면 오차가 줄어듭니다.

8. 학습 = 컴퓨터가 손잡이를 돌리기

오차: · 반복 0번

컴퓨터는 "손잡이를 어느 쪽으로 조금 돌리면 오차가 줄어드나"를 계산해서 조금씩 돌리기를 수천 번 반복합니다. 이게 학습입니다.

9. 손잡이 종류

방식손잡이 수무엇을 고치나
물리 보정27개센서 기본 오차, 배율, 축 비뚤어짐, 카메라–센서 거리. 폰마다 고정된 성질
CNN17만 개진동·온도·동작에 따라 바뀌는 오차. 센서 값의 "모양"을 보고 그때그때 고침

손잡이가 많을수록 더 많이 고칠 수 있지만, 데이터가 적으면 외우기만 합니다. 그래서 단순한 것(물리 보정)부터 맞추고, 남은 것만 CNN이 맡습니다.

10. 시험: 안 본 녹화로 채점

학습에 쓴 녹화로 채점하면 답을 외운 것도 점수가 좋게 나옵니다. 그래서 녹화 하나는 학습에 절대 안 쓰고 시험용으로 둡니다.

시험 점수가 좋아져야 "진짜로 고친 것"입니다.
