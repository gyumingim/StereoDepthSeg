# Z2 나누어 보기 계획 (2026-10-21, 사전 등록 — 실행 전에 커밋)

질문: Z2 (`zupt_chi2_multipler 1` + `zupt_noise_multiplier 1`) 가 내려놓기 실패는 고쳤지만 새 무너짐 2 개
(F_221052 o1: 1.4 → 70.7 cm, O_131326 o0: 4.2 → 22.5 cm) 와 헛 통과를 만들었다 (docs/z2_regression.html).
**어느 쪽 변경이 무너짐을 만드나? 내려놓기를 고치면서 회귀가 없는 변형이 있나?**

## 고정 조건 (z2_regression_plan.md 와 같음)
- 벤치 경로·인자·초기화(정적 전용, 창 1.0 s, 시차 15 px)·clones 11·640x360@60·잡음 cfg·디코드 2 스레드 — z2_regress.jobs() 의 인자를 그대로 씀.
- 코드 한 버전: vio_bench_hs.py·c5_run.py·브리지·OpenVINS 라이브러리 **안 고침** (z2_regress·setdown_mitig 와 같은 blob).
  실행기 imu_learn/z2_isolate.py (조건만 바꿈). 분석이 버전 수를 세어 1 이 아니면 표시.
- 동시 OpenVINS ≤ 3, nice 5, 분리 실행(setsid nohup).

## 조건 (한 번에 하나만 바꿈 — base 기준)
| 이름 | 바꾸는 것 | 뜻 |
|---|---|---|
| base | 없음 (chi2 0 = 시차만, 잡음 ×10) | 기준 |
| Z2 | chi2 1 + 잡음 1 | 문제 조합 (z2_regress 결과 복사) |
| Z1 | chi2 1 만 | IMU 만으로 정지 받기 켬, 잡음 ×10 그대로 |
| N1 | 잡음 1 만 (chi2 0) | IMU 판정 꺼진 채 정지 갱신만 세게 (시차 통과 때만 ZUPT) |
| H | `--still-hold 1.0:0.05:0.05` | 바깥 IMU 정지 판정, ZUPT 설정 그대로 |
| Z2c | chi2 0.5 + 잡음 1 | Z2 보다 IMU 정지 판정(chi² 문턱) 더 깐깐 |
| Z2v | Z2 + `zupt_max_velocity 0.05` | Z2 보다 속도 문턱 더 깐깐 (0.1 → 0.05 m/s) |

- "추적 시작 시각을 같게 강제" 하는 변형은 벤치에 그런 장치가 없어 **못 만든다** (코드를 고치면 한 버전 규칙 위반).
  대신 실행마다 시각 3 개를 기록해 비교한다: OpenVINS 초기화 로그 시각, 첫 시각 갱신(특징 > 0) 시각, 첫 tracking 포즈 시각(t_init_clip_s),
  그리고 초기화 ~ 첫 시각 갱신 사이 ZUPT 통과 수. → Z1 (IMU 받기) 과 N1 (잡음) 을 따로 보고, 시각 차이와 무너짐이 같이 가는지 본다.

## 판정 (z2_regression_plan.md 와 같음, 조건 V 대 base, 묶음 = 녹화(F/O) 또는 녹화×S(T), 반복 3)
1. **ATE**: V 의 ATE 중앙값 ≤ max(base × 1.10, base + 0.2 cm).
2. **새 무너짐 0**: 같은 짝에서 base 성공인데 V 가 무너짐·미판정·초기화 안 됨 (base 초기화 안 됨 → V 무너짐도 셈).
3. **헛 통과 0**: "시차 실패 + ZUPT 통과" 프레임 중 정답 속도 > 2 cm/s 수 = 0 (z2_regress.analyse_one 그대로).
   - H 와 N1 은 chi2 0 이라 IMU 만으로 통과가 구조상 없다 → 3 은 자동 0. 보조로 전체 ZUPT 중 정답 속도 > 2 cm/s 수를 base 와 같이 적는다.
- 추가 표시 (검증자 요청, 판정엔 안 씀): 짝별 최악 (V − base ATE) 와 짝 단위로 1 의 한도를 넘은 짝.
- **내려놓기 고침** (setdown_mitigation_plan 규칙): 224323 마지막 3 s 창 오차 중앙값 ≤ base 50 % **그리고** 끝 정지 이동 중앙값 ≤ base 50 %.
- **원인 판정**: 두 무너짐 짝 (F_221052_o1, O_131326_o0) 에서 Z1·N1 중 무너지는 쪽이 원인 (추정). 둘 다 → "둘 다 혼자서도", 둘 다 아님 →
  "조합에서만".
- **최선 조건**: 내려놓기를 고치는 조건 중 1 단계 실패 묶음 수 → 새 무너짐 수 → 헛 통과 수 → 224323 마지막 창 오차 순으로 가장 작은 것.
  고치는 조건이 없으면 같은 순서로 전체에서 고르고 "내려놓기 못 고침" 으로 적는다.
- **최종**: 최선 조건이 1 + 2 단계 전체 묶음에서 1–3 을 모두 지키면 "회귀 없음 (추정)".
- 녹화가 적고 같은 방·손 움직임 → 모든 결론은 **추정**.
