## 유의성 ((e) vs loose, 짝 비교)
- 이전 붕괴 7 개 × 시작 2 개: loose 만 붕괴한 짝 7, (e) 만 붕괴한 짝 0 → 실행 단위 McNemar 정확 검정 p = 2·0.5^7 ≈ 0.016.
  그러나 같은 녹화의 실행은 독립이 아니다 (계획 7절). 그래서 녹화 단위로 봐야 한다.
- 녹화 단위로 붕괴가 줄어든 녹화 4 개 (115620, 132803, 145816, 151358), 늘어난 녹화 0 개, 같음 3 개 → 부호 검정 양측 p = 0.125.
  "사라짐" 기준으로는 3 대 0 → p = 0.25.
- (d) vs loose: 2 대 0 → p = 0.5. (e) vs (d): 3 대 0 → p = 0.25.
- → "clone 창 효과가 더 크다" 는 유의하지 않다. 방향이 같다는 정도이고, 사후 탐색이며 녹화는 11 개다. HTML 은 "추정" 이라고 적었지만, 굵은 글씨의 "더 큰 효과" 는 표현이 세다.
