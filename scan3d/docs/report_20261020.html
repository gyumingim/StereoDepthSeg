ATE = 전체 위치 오차, RPE1s = 1초 동안 흘러간 오차, 스케일 = VIO 크기/정답 크기. 물리 보정은 그 녹화를 빼고 학습한 값만 사용(공정).

4. 밤사이 사고와 고친 것

  • 정답 만드는 스크립트가 지워져 있었음 (Windows 쪽 셸로 WSL 파일을 고친 것이 원인) → 복구, 규칙으로 저장.
  • 회전 곡선이 180° 넘게 돌면 깨지는 버그 (6번 녹화 6°) → 1초 조각으로 고쳐 0.12°.
  • 학습 8개를 동시에 돌렸더니 예상보다 훨씬 느려 VIO 비교를 줄여서 실행 (녹화 2개 × 60초).
  • WSL 쪽 git 은 GitHub 로그인이 없어 그동안 push 가 안 됐음 → Windows git 으로 push (전부 올라감).

5. 오늘 할 것 / 정할 것

  1. OpenVINS 설정 확정: IMU 잡음 = 실측 ×10 (두 녹화 모두 좋아짐), 물리 보정값(축척·축·바이어스·레버암) + 시간차 −2 ms. 폰 설정 파일로 만들어 둠.
  2. 120 fps 를 쓰려면 OpenVINS 수정: 추적은 매 장, 갱신(복제 상태)은 더 긴 간격 — 지금 그대로는 발산.
  3. 카메라 끊김 뒤 복구 개선: 돌아온 직후 0.6~2.6 m 튐 → 끊김 감지 시 특징점 리셋·상태 유지 재시작 (ov_bridge 의 reinit-state 활용).
  4. 폰에서 OpenVINS 속도 실측 (60 fps, 해상도·특징점 수별) — 폰 연결만 해 주시면 제가 돌림.
  5. CNN 은 접기 (데이터 10 배에도 +1.6 %). (선택) 넓은 실제 공간 VIO 녹화.
