# 초점 거리에 따른 화면 크기 변화 (2026-10-22, 사용자와 함께 측정)

**결론:** 초점을 1 dpt 가까이 할 때마다 화면이 **약 0.8 % 커진다** (선형). 얇은 렌즈 계산(0.55 %/dpt)보다 약 1.4 배 크다.
그래서 초점마다 카메라 보정값(초점거리 fx, fy)을 `K(D) = K(D_ref) × (1 + 0.0080 × (D − D_ref))` 로 고치면 된다 (D = 초점 dpt). 주점(cx, cy)은 이번에 따로 재지 않았다.

| 초점 | 화면 크기 (2.7 m 기준) | 얇은 렌즈 예측 | 선명도 (라플라시안 분산) |
|---|---|---|---|
| 0.37 dpt (2.7 m) | 0 (기준; 중앙값 −0.075 %) | 0 | 108 |
| 1.00 dpt (1 m) | +0.38 % | +0.34 % | 146 |
| 2.22 dpt (45 cm) | +1.35 % | +1.01 % | 258 |
| 3.33 dpt (30 cm) | +2.26 % | +1.63 % | 132 |

- 녹화: 폰 hs_20261022_105441 (앱 v0.6.2, focus_sweep 0.37/1.0/2.22/3.33, 단계마다 2 s, 240 fps 1920×1080), 회사 모니터 보드를 약 45 cm 에서 찍음. 선명도는 보드 거리(45 cm)에서 가장 높음.
- 방법: ArUco 마커 모서리를 6 프레임마다 검출 (렌즈 움직임 뒤 60 ms 는 뺌), 기준 초점 평균 위치에 닮음 변환을 맞춰 배율을 구함. 단계마다 프레임 142–180 장. 2.22·3.33 dpt 의 p10–p90 폭은 ±0.02 %, 흐린 0.37·1.0 dpt 는 ±0.2 %.
- 폰이 보고하는 프레임별 보정값(LENS_INTRINSIC_CALIBRATION)은 240 fps 모드에서 모두 0 이라 쓸 수 없다 (hs_20261022_103358).
- 렌즈가 초점을 옮기는 시간: 약 17–33 ms (lens_state = 1 인 결과 1–2 개).
- 한계: 한 번, 한 거리에서 잰 값. 화면 가장자리 쪽 왜곡 변화는 재지 않음. 손이 화면 앞에 일부 들어옴 (보드만 쓰므로 영향 작음, 추정).
- 코드: imu_learn/focus_scale.py
