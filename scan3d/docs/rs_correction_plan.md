# 롤링셔터(RS) 특징점 보정 비교 — 계획 (2026-10-23, 실행 전 커밋)

조사 = `docs/rolling_shutter_survey.md` 4.3 절 1순위 (특징점 단위 자이로 회전 보정). 이 문서는 **비교를 돌리기 전에** 기준을 고정한다.

## 무엇을 바꾸나 (구현)
- OpenVINS 사본 `~/scanner/src/open_vins_rs` = `open_vins_zbase` (stock + 진단 로그 줄만) + `tools/ov_patches/rs.diff`.
  빌드 `~/scanner/src/ovbuild_rs`, 다리 `tools/ov_bridge_rs` (= `ov_bridge/main.cpp` 92320b7 그대로 복사, 링크만 바꿈).
- 새 설정 키 2 개 (없으면 기본값):
  - `rs_readout_time` (s, 부호 있음, > 0 = 넣은 영상의 위 행이 먼저). **0 = 꺼짐 (기본)** → 새 코드가 전혀 실행되지 않는다.
  - `rs_row_scale` = 넣은 영상 행 비율 → 원본 센서 행 비율 (undistort 크롭). 렌즈에서 계산 `fy_raw·H_fed / (fy_fed·H_raw)`, 조정값 아님.
- 동작: 트래커가 이 프레임 측정을 DB 에 넣은 직후, 각 특징의 행 v 에 대해
  `τ = rs_readout_time · rs_row_scale · (v/H − 0.5)`, 프레임 시각 ± (readout/2 + 2 ms) 안의 자이로 평균 ω (초기화 후 bias 뺌),
  `b_ref = Exp(R_ItoC ω τ) · b_row` 로 베어링을 가운데 행 시각으로 돌리고 `uvs`, `uvs_norm` 둘 다 바꾼다 (잔차는 uvs, 삼각측량은 uvs_norm 을 씀).
  KLT 는 자기 점 목록을 쓰므로 추적은 그대로다.
- 기준 행 = 가운데: 프레임 시각 `t_mid = 센서 ts + 노출/2 + skew/2` (앱 1.7-mid) 이고, align.json 의 dt 도 이 시각 기준.
- 가정 (확인 안 됨): (1) 녹화 영상의 위→아래 = 센서 읽기 순서 (회전 메타 없음, 반대면 부호가 바뀐다 — 정상성 시험의 flip 비교로 일부 확인),
  (2) 읽기 시간이 노출 중에 일정하고 ω 가 3 ms 동안 일정, (3) 병진·깊이 효과 무시 (조사 4.1: 5 m/s·5 m 에서 1.3 px, 실내 손 이동은 훨씬 작음, 추정),
  (4) undistort 의 비선형(왜곡) 부분은 행 시각 계산에서 무시 (크롭 비율만 반영).

## 기준 (판정 규칙, 조건마다)
채점 = `zupt_ob_score.run_metrics` (GT 중심 p_bc, 창 = 첫 추적 포즈 ~ 마지막 GT 표본), phone60 과 같음.
- **(a) 발산 수 (안 나빠짐)**: 아무 5 s 창 상대 오차 > 30 cm 또는 창 ATE > 50 cm 인 run 수 (213955 제외). RS ≤ base 이면 통과.
- **(b) ATE 안 나빠짐**: 두 조건 모두 발산 아닌 칸의 창 ATE 중앙값. RS ≤ 1.2 × base + 0.3 cm 이면 통과.
- **(c) 1차 개선 기준**: 같은 정상 칸에서 RS 중앙값 ≤ 0.9 × base **그리고** RS 가 base 보다 ATE 가 작은 칸이 절반 초과.
- 판정: (a)(b)(c) 모두 통과 → 그 skew 로 채택. 둘 다 통과하면 (c) 의 중앙값이 더 작은 쪽. 아니면 꺼둔 채 유지.
  (a)(b) 만 통과 = "해롭지 않지만 이득 확인 안 됨" 으로 보고 (채택 아님).
- 보고: 녹화별 ATE, 발산 수, 온라인 시간 오프셋 (dt_cam_imu_final), run 당 시간. 반복 1 회라 칸 단위 잡음이 있다 (phone60 와 같은 한계).

## 2 단계 설계 메모 (지금 구현 안 함)
- 병진 RS 는 미리 보정할 수 없다 (깊이를 모름). **필터 업데이트 안에서** 다룬다:
  각 측정의 행 시각 τ 에 대해 카메라 자세를 `T(t+τ) ≈ T(t) ⊕ (ω τ, v τ)` 로 1 차 외삽하고 (v = 필터 상태 속도, ω = 자이로 − bias),
  특징 깊이는 그 특징의 현재 추정 (MSCKF 삼각측량 / SLAM 랜드마크) 을 쓴다. 자코비안에 v·τ 항 (상태 속도에 대한 미분) 을 더한다.
  Li & Mourikis (IJRR 2014) / VINS-Mono `projection_td_factor` 와 같은 계열.
- 그때는 회전도 업데이트 안으로 옮기거나 (권장, 중복 방지), 회전 사전 보정 + 병진만 업데이트로 나눈다.
- 병진이 큰 녹화 (214550, 213341, 223815, 224323) 에서 따로 효과를 보는 것을 우선한다.
