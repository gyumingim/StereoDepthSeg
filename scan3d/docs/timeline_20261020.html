학습 1개 안의 단계반복 수걸린 시간반복 1번

원인: 3초 창의 IMU 를 적분할 때 1,500 걸음을 Python 반복문으로 하나씩 GPU 에 보냅니다. 걸음 하나하나는 아주 작은 계산이라 GPU 는 대부분 "다음 지시"를 기다리며 놀고, 프로세스가 여러 개면 그 지시 줄에서 서로 기다립니다. 그래서 동시에 많이 돌려도 빨라지지 않았습니다.
