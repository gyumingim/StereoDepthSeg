1왜 보정하나 — IMU 오차는 시간이 갈수록 커진다

IMU는 두 가지를 잽니다.

  • 자이로: 폰이 얼마나 빨리 돌고 있는지 (초당 몇 rad)
  • 가속도계: 폰이 얼마나 밀리고 있는지 + 중력 (m/s²)

위치를 알려면 가속도를 두 번 더해야(적분) 합니다. 가속도 → 속도 → 위치. 그런데 IMU 값에는 늘 작은 오차가 섞여 있습니다.

IMU가 준 값 = 진짜 값 × (축척 오차) + 축 어긋남 + 바이어스(늘 붙는 작은 값) + 잡음

가속도에 바이어스 b가 있으면 위치 오차는 ½ · b · t² — 시간의 제곱으로 커집니다. 아래에서 직접 움직여 보세요.

그래서 "작은 바이어스 하나 빼기"만 해도 몇 초 뒤 위치가 크게 달라집니다. 자이로 오차는 더 무섭습니다 — 자세가 조금 틀리면 중력(9.8 m/s²)이 엉뚱한 방향으로 새어 들어가 가속도 오차가 됩니다 (1° 틀리면 0.17 m/s²).

목표: IMU 값에서 이런 오차를 빼 주는 "보정"을 찾는 것. 보정이 좋으면 카메라가 잠깐 안 보일 때(가려짐·어둠·빠른 움직임) IMU만으로 버티는 시간이 길어집니다.

6IMU로 위치 계산하기 (물리 적분)

IMU 값 하나(2 ms마다)가 들어올 때마다 아래 네 줄을 반복합니다. 이게 전부입니다.

R ← R · exp(ω · dt) ① 자세: 자이로 ω만큼 2 ms 동안 돌림 a = R · f + g ② 가속도 f(폰 기준)를 보드 기준으로 돌리고 중력 g를 더함 v ← v + a · dt ③ 속도에 더함 p ← p + v · dt + ½ a · dt² ④ 위치에 더함
  • R: 폰이 보드에 대해 어느 쪽을 보는지 (3×3 회전). ω: 자이로. dt: 2 ms.
  • f: 가속도계 값. 가만히 있어도 +9.8 m/s²(위쪽)이 나옵니다 — 중력을 버티는 힘을 재기 때문. 그래서 ②에서 g(아래로 9.8)를 더하면 가만히 있을 땐 a = 0.
  • g(보드 좌표에서 중력 방향)는 녹화마다 IMU로 맞춥니다 — 보드(모니터)가 약간 기울어져 있어서.

이 계산은 정확한 물리 공식이라 틀릴 게 없습니다. 틀리는 건 들어가는 ω와 f뿐 → 그래서 보정은 "ω와 f를 고치는 것"입니다.

7IMU 계산과 정답을 비교하는 법 (3초 창)

녹화를 3초짜리 창으로 자릅니다 (0.25초씩 밀면서 겹치게). 창마다:

  1. 창의 첫 정답 사진의 자세 R에서 출발 (위치는 0).
  2. 3초 동안 IMU를 적분해 모든 순간의 R, p를 계산.
  3. 창 안의 정답 사진 전부(240 fps면 최대 약 700장)와 비교.

시작 속도를 모르는 문제

적분하려면 시작 속도가 필요한데, 정답 위치를 미분해서 속도를 구하면 잡음이 큽니다. 그래서 시작 위치 p0와 시작 속도 v0를 "가장 잘 맞게" 계산으로 정합니다 (최소제곱). 그 뒤 남는 차이만 오차로 봅니다.

정답 p_j ≈ IMU 적분 q_j + p0 + v0 · τ_j (τ_j = 창 시작부터 그 사진까지 시간) → p0, v0 를 직선 맞추기로 구하고, 남은 차이 = "위치 잔차"

즉 이 오차는 "IMU가 궤적의 휘어짐(가속·회전)을 얼마나 정확히 설명하나"입니다. 표에 나오는 두 숫자:

  • 위치 오차 (cm): 창 안 위치 잔차의 RMS, 창들의 중앙값.
  • 회전 오차 (°): 창 끝(3초 뒤) 자세가 정답과 몇 도 다른지, 중앙값.

레버암 r이 왜 필요: 정답은 카메라 위치인데 적분은 IMU 위치. 폰을 돌리기만 해도 두 점은 다르게 움직입니다. 1번 녹화에서 찾은 r ≈ (4.4, 0.5, 2.1) cm — 폰 안에서 그럴듯한 거리.

9학습 — 숫자를 어떻게 찾나

적분 네 줄(6장)이 모두 미분 가능한 계산이라, "보정 숫자를 아주 조금 바꾸면 오차가 얼마나 변하나"를 컴퓨터가 자동으로 구할 수 있습니다. 그 방향으로 숫자를 조금씩 고치기를 수천 번 반복 = 경사하강.

손실 = 평균 [ (회전 오차 / 0.005 rad)² + (위치 잔차 / 1 cm)² ] × 가중치 가중치 = 1 / (1 + (그 순간 회전 빠르기 / 1 rad/s)²) ← 빨리 돌 때 정답을 덜 믿음 (흐림·롤링셔터)
  • 학습 / 평가 나누기: 학습에 쓴 구간과 다른 구간(또는 다른 녹화)으로 점수를 매겨야 진짜 실력. 학습 구간 점수만 좋으면 = 외운 것(과적합).
  • 물리 보정의 벌점: 행렬이 단위행렬에서 너무 멀어지면 작은 벌점 → 정답 잡음까지 외우는 걸 막음.
  • 중력 방향: 보정 전에 녹화마다 원래 IMU로 먼저 맞춰 둠 → 모든 모델이 같은 출발선.
  • 순서: 바이어스만 → 물리 보정 → (물리 보정 고정) + CNN → CNN 혼자 (비교용).

11다음에 할 것 · 판단 기준

  1. 데이터 늘리기: 45 cm 고정 초점으로 녹화를 더 모음 (지금 약 8분). CNN은 수십 분은 있어야 의미가 있을 가능성이 큼(추정).
  2. 렌즈 값 하나로: 고정 초점 녹화들은 렌즈 값을 많은 사진으로 한 번 정확히 구해 같이 씀 (지금은 녹화마다 80장으로 따로 구해 3 % 차이 — 확인 중).
  3. 녹화 단위로 나눠 평가: 4개 중 하나씩 빼고 학습 → 뺀 것으로 평가 (가장 정직한 점수).
  4. 판단 기준: 처음 보는 녹화에서 바이어스만보다 30 % 이상 좋아지면 CNN을 계속, 아니면 물리 보정까지만 쓰고 다음 단계(VIO 결합)로.
