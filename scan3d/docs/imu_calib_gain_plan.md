# 자이로 바이어스 보정 이득 — 사전 등록 (Part 1, 분석만)

만든 때 2026-10-22, 계산 전에 커밋. 배경: `docs/endstill_bias_20261021.md` (150 s 동안 바이어스 +50–60 mdeg/s, type 4 잔여 약 40 mdeg/s · 70 mdeg/s 계단).
질문: "IMU (자이로) 보정을 하면 회전 오차가 얼마나 줄어드나" 를 숫자 하나로.

## 입력
- 녹화 (spline GT `imu_gt_spl/gt.npz` 가 있는 hs_ 녹화): 10-21 `213341`, `214550`, `215348` (213955 는 폰 떨어짐 확인 → 제외),
  10-20 `214138`, `221052`, `221903`, `221925`, `222747`, `223815`, `224323`.
  - 계산 전 확인된 사항: `221925` 는 IMU 정지 구간이 없음 → 보정 정지가 없어 제외. `221903` 은 GT 유효 234 프레임 (약 1 s) → 10 s 창이 없어 제외 (아래 최소 창 수 규칙으로 자동 제외).
- GT = `imu_gt_spl/gt.npz` 의 `R_bc` (카메라→보드 회전, 시각 `t_ns` 카메라 시계, `ok` 프레임만). 이 GT 는 IMU 항 없이 맞춤 (`board.json` imu_terms False) → 자이로와 독립.
- 자이로: `imu.csv` type 16 v0..2 (raw), type 4 (안드로이드 보정). 읽기는 `imu_learn/imu_gt.read_imu`.
- 카메라–IMU 회전·시각: 기존 녹화별 보정 `imu_gt/align.json` 의 `R_ci` (IMU→카메라, ω_cam = R_ci ω_imu) 와 `dt_ns` (IMU 시각 + dt = 카메라 시각). 새로 맞추지 않음.
  (config/mono 의 kalibr `T_imu_cam` 은 렌즈 2 정류 카메라 기준이라 GT 카메라 (렌즈 5) 와 다름 → 쓰지 않음, 차이만 참고로 적음.)
- 정지 검출: `imu_learn/i3_confirm.still_runs` (raw type 16 에 적용, 그대로 import).

## 지표 (모든 조건 같은 창, 같은 채점)
- 창: 보정 정지 (= 녹화의 첫 정지 구간) 끝 이후의 **모든 GT 유효 프레임** t0 에서 시작, 길이 10 s. 끝 t1 = t0 + 10 s 에 가장 가까운 GT 유효 프레임 (|차| ≤ 10 ms, 없으면 그 창 버림). t1 이 녹화 끝을 넘으면 버림.
- 자이로 적분: 녹화 전체를 한 번 적분 (각 표본 구간 ω 일정, 바이어스 b(t) 는 그 시각에 쓸 수 있는 값) → 창의 상대 회전 R_est = R_ci · Q(t0)ᵀQ(t1) · R_ciᵀ (자이로 시각 = 카메라 시각 − dt).
- GT 상대 회전 R_gt = R_bc(t0)ᵀ R_bc(t1). 오차 = ∠(R_gtᵀ R_est) (deg).
- 보고: 녹화별 **중앙값**, **p90** (deg), **요 드리프트율** (deg/min) = 오차 회전을 보드 좌표에서 중력축에 투영한 성분 |φ·ĝ| / 10 s × 60 의 중앙값.
  중력 ĝ (보드 좌표) = 보정 정지 동안 가속도 (type 1) 평균을 R_ci, R_bc 로 보드 좌표로 옮긴 것.
- 헤드라인: 녹화별 중앙값의 중앙값 (B → D), 감소율 %.
- 최소 창 수 100 개 미만 녹화는 제외.

## 조건
- **A** raw type 16, 바이어스 보정 없음.
- **B** 안드로이드 type 4 (그대로).
- **C** raw − 보정 정지 평균 (녹화 내내 고정).
- **D** raw − 정지마다 다시 잡은 바이어스, 인과적: 시각 t 에서 바이어스 = 끝난 정지 중 가장 최근 것의 평균 (정지가 끝난 순간부터 적용; 끝나기 전에는 이전 값).
  보정 정지 끝 전에는 C 와 같음 (창은 그 뒤에서만 시작).
- **E** raw − 녹화 전체 최적 상수 바이어스 (oracle, 참고 상한만): GT 유효 프레임에서 b = 평균(ω_raw − R_ciᵀ ω_gt), ω_gt = 이웃 GT 프레임 상대 회전의 log / Δt.
- 정지 평균 규칙 (C, D 공통): 정지 길이 ≥ 4 s 면 앞 2 s 잘라 평균 (내려놓은 뒤 흔들림, endstill 문서), 아니면 전체 평균.

## 판정 규칙
- **D 가 B 보다 낫다** = 중앙값 오차가 B 보다 **20 % 이상 낮은** 녹화가 **3 개 이상**.
- 같은 방식으로 D vs C (재보정 이득) 도 보고 (판정은 D vs B 만).
- 상식 시험 먼저: E 의 녹화별 중앙값이 2 deg 넘으면 (축·부호·시각 의심) 지표를 믿지 말고 원인부터 찾음. 찾은 수정은 결과 문서에 적음.

## 섞인 변수 · 한계 (미리 적음)
- 10-20 녹화는 정지가 1–2 개 → D ≈ C. D 와 C 의 차이는 주로 10-21 녹화 (정지 3 개) 에서 나옴.
- 창은 서로 겹침 (프레임마다 시작) → 창 수는 독립 표본 수가 아님. 녹화 수 (최대 8) 가 실제 반복 수.
- R_ci 는 같은 녹화의 자이로로 맞춘 값 (회전만; 바이어스 3 mrad/s 는 ω 0.8 rad/s 에 비해 작아 영향 작다고 추정).
- Part 2 (OpenVINS 에 D 보정 IMU 넣기) 는 Part 1 에서 D 가 이기면 따로 사전 등록.
