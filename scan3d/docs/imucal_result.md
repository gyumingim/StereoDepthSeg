## 결론 먼저
- **네 변형 모두 "해 없음, 개선 아님"** (사전 기준 (a)(b) 통과, (c) 개선 기준은 못 넘음). 발산 수는 모두 base 와 같음 (2 = 131326, 224323).
- **C4 (카메라–IMU 거리) 가 가장 좋음**: 정상 12 칸 **모두** ATE 가 줄거나 같음 (중앙값 0.90 → 0.87 cm, 큰 칸에서 크게: 134550 1.90 → 1.25, 134204 2.45 → 1.99, 223815 0.74 → 0.40),
  |축척 − 1| 중앙값 0.0216 → 0.0174 (−19 %). 기준 (c) 의 −10 % / −30 % 에는 못 미침. → **사용자 결정 2026-10-23: 거리 보정 채택 (기본 켬).**
- C1 (6 면 가속도): 축척 오차는 줄지만 (0.0216 → 0.0163, −25 %, 기준 −30 % 미달) ATE 는 약간 늘음 (0.90 → 0.92). 이득 불확실.
- C2 (자이로 정지마다 재보정): 거의 그대로 (중앙값 같음, 바뀐 칸 3 개 모두 0.01–0.12 cm 감소). 예전 결과 (`docs/gyro_rebias_apply.md` Part 2) 와 같음.
- C3 (C1 + C2): C1 과 거의 같음.
- **자 (점수) 문제 발견**: 예전 창 ATE 는 포즈 `p` = **IMU 위치** 를 카메라 GT 와 비교했다. 같은 base 를 카메라 위치로 재면 정상 칸 중앙값 **2.16 → 0.90 cm**.
  즉 이전 문서들의 창 ATE (phone60·initgyro 등) 는 카메라–IMU 거리 (온라인 추정, 수 cm) 만큼 부풀어 있었다. 발산 판정은 이번 15 칸에서는 두 자가 같았다.
