1. 문제: 작은 오차가 점점 커진다

폰 센서(IMU)는 아주 조금씩 틀립니다. 그런데 위치는 센서 값을 계속 더해서 구하기 때문에, 작은 오차가 시간이 갈수록 쌓여서 커집니다.

초록 = 실제로 간 길, 빨강 = 센서 값 그대로 계산한 길

2. 해결: 오차를 미리 빼 주는 "번역기"

센서 값을 계산에 넣기 전에 CNN이 "여기는 이만큼 틀렸어" 하고 고쳐 줍니다. 위치 계산은 원래 공식 그대로입니다.

3. CNN은 어떻게 알아보나: "모양 카드"로 훑기

CNN은 짧은 모양 카드를 신호 위로 밀면서, 카드와 닮은 곳에서 불이 켜집니다(아래 막대). 카드를 바꿔 보세요.

4. 카드를 여러 장 쓰면

카드마다 찾는 모양이 다릅니다. 여러 장을 동시에 쓰면 "어디에 어떤 움직임이 있는지" 한눈에 정리됩니다. (실제로는 32~128장)

5. 층을 쌓으면: 작은 모양 → 큰 동작

글자를 읽을 때 획 → 글자 → 단어로 묶듯이, 1층은 짧은 떨림, 위층은 그걸 묶어 "기울이며 빨라지는 동작"을 알아봅니다. 4~5층이면 약 1초를 봅니다.

6. 카드는 누가 만드나: 스스로 배운다

처음 카드는 엉망입니다. 계산한 위치를 보정판으로 잰 정답과 비교해서, 틀린 만큼 카드를 조금씩 고치기를 수천 번 반복하면 오차가 줄어듭니다.

요약

① 센서 오차가 쌓여서 위치가 틀어진다.

② CNN이 짧은 "모양 카드"로 센서 신호를 훑어 오차를 알아보고 미리 빼 준다.

③ 카드는 보정판 정답과 비교하며 스스로 배운다. 계산은 가벼워서 폰에서 1 ms 안팎(추정).
