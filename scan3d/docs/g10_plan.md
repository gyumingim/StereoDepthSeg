## 판정 (실행 전에 고정)
1. **안전:** (a) 모든 칸에서 G 헛 통과 수 ≤ 같은 칸 base 헛 통과 수. (b) 새 무너짐 0: base 정상 (ok) 인데 G 가 무너짐 · 초기화 못 함 · 채점 안 됨인 칸 0 개
   (출발 칸은 출발 창 상태, R 칸은 전체 상태). 둘 다 → 통과.
2. **회귀:** R 칸 중 G 의 문이 실제로 한 번이라도 열린 칸 (G 실행 JSON g10_gate_open_frames > 0) 에서, base · G 모두 채점된 칸의 전체 ATE 짝 차이 (G − base)
   (a) 중앙값 ≤ +0.1 cm, (b) 칸별 최대 악화 ≤ 시작 민감도 띠.
   시작 민감도 띠 = 213341 d1 · d5 각각, base 와 i3 각각에서 시작 −0.25 / 0 / +0.25 s 세 실행의 출발 10 s ATE 의 (최대 − 최소), 그 4 개 중 최대 (G 실행은 띠에 안 씀).
   채점된 실행이 2 개 미만인 묶음은 띠 계산에서 뺀다. 띠를 못 구하면 (b) "판정 불가".
   (문이 한 번도 안 열린 R 칸은 짝 차이 0 이 구성상 정해지므로 중앙값에 넣지 않는다 — 넣으면 중앙값이 저절로 0 이 됨. 참고로 따로 적는다.)
   (주의: 띠는 출발 10 s ATE 에서, R 짝 차이는 전체 ATE 에서 잰 값이다 — 제안 문구 그대로이며 단위만 같다.)
3. **이득 (214550 만):** 214550 의 시험 칸 (B 3 + B′a 3 + B′b 2 중 실행 가능한 칸) 에서 출발 뒤 10 s ATE 짝 차이 (G − base) 중앙값 < 0,
   그리고 "base 무너짐 & G 정상" 칸 ≥ 2. 둘 다 → 통과.
4. **보고:** 규칙 판정 (1–3) 과 짝 판정 (칸별 G − base, i3 − base, G − i3 / 좋음 · 같음(±0.05 cm) · 나쁨 개수, 부호 뒤집기 p) 을 나란히.
   i3_takeoff 의 (i)(ii)(iii) 규칙을 G 대 base 로 그대로 적용한 값도 참고로 적는다.
   결론은 **"214550 에서 효과 있음 / 확인 안 됨 + 안전 통과 / 실패 + 회귀 통과 / 실패"** 까지만 (녹화 1 개, 추정). "녹화 ≥ 2" 이득 확정은 새 녹화 뒤.
- 같은 녹화의 칸들은 독립 반복이 아니다. 섞인 변수: 없음 (G 와 base 의 차이는 문턱 하나; 브리지 바이너리가 다르지만 동일성 점검 1 로 확인).
