## 4. 지표·판정 (계획의 판정 기준을 그대로 숫자로)
- 성공 = 초기화 (tracking) 되고, 초기화 뒤 첫 10 s 창 (없으면 5 s) Sim3 축척 0.5~2 그리고 SE3 ATE < 10 cm (C5 의 collapse_signals.label 과 같은 식).
  무너짐 = 초기화됐는데 성공 아님. 초기화 안 됨 = 따로 셈. 이름표 없음 (정답 매칭 < 30) = 따로.
- 주 지표 = 성공 실행의 초기화 뒤 전체 SE3 ATE (cm). 보조 = 성공률, Sim3 ATE·축척, 10 s 창 ATE 중앙값, 초기화 시각, 추적 비율.
- **C5**: 처음 정지 있는 녹화에서, 이름표 붙은 실행 중 무너짐 비율 strict (a) ≤ ½ × loose (c) 이면 "지지", 아니면 "지지 안 함".
  (a) 나 (c) 의 이름표 실행이 2 개 미만인 녹화 = 시험 안 됨. (a) 가 시험된 녹화가 없으면 "판정 불가 (초기화 안 됨)",
  loose 무너짐이 0 이면 "판정 불가 (줄일 무너짐 없음)". 녹화 단위 부호 검정 (무너짐 비율 a<c vs a>c); 녹화 < 6 이거나 p ≥ 0.05 면 "근거 약함".
- **B·C·N** (계획: "반복 흩어짐보다 작으면 차이 없음"): 녹화마다 두 조건의 성공 실행 ATE 중앙값 차이를, 반복 흩어짐 = 두 조건 각각의
  (최대−최소) 중 큰 값과 비교. |차이| ≤ 흩어짐 → 같음, 아니면 나음/나쁨. 어느 쪽이든 성공 < 2 → 시험 안 됨. 녹화 단위 나음 대 나쁨 부호 검정,
  같은 "근거 약함" 규칙. 성공 수 차이도 녹화 단위로 같이 적는다.
- 축척: 모든 ATE 는 정답 칸 40.70 mm (추정) 기준. 포즈를 저장하므로 `c5_overnight_analyse.py` 를 정답 축척을 고친 뒤 다시 돌리면 전부 다시 계산된다.
