## 결론 (먼저)

**A 는 채택하지 않는다. 기준 1·2·3 실패, 4 통과.** 판정 규칙에 따르면 1 이 실패했으므로 다음은 기전 재조사이다 (C·D 는 이번에 하지 않음).

- 표적 붕괴는 막았다: 133820 ATE 280–386 cm → 1.2–4.7 cm, 134550 o2 18.5 → 0.8 cm, SLAM 전멸 6/6 → 0/6.
- 그러나 133820 의 A run 3 개에 "전부 거절 갱신"이 1–2 회씩 남았다 (기준 1 은 0 회 요구). ZUPT 틈과는 관계가 없다 (아래).
- 회귀 쪽에서 새 붕괴가 나왔다. 154320 o0 은 ATE 11 → 501 cm, 214550 o2 는 10.6 s 에 새 전멸이 생겼다 (ATE 는 20.7 → 9.7 cm 로 좋아졌는데도). 213955 는 기준선부터 3/3 붕괴였고, A 에서 전멸 수가 달라졌다 (o1 은 12 → 5234 cm).
- 214550 o1 ATE 18.3 → 27.2 cm 로 한계(20.1) 초과.
- 반대로 기준선에서 붕괴한 222747 3 run (ATE 121–6842 cm) 은 A 에서 1.1–1.5 cm 로 살아났다.
  215348 에서도 기준선의 전멸 1–2 회가 0 회가 됐다. 판정에는 쓰지 않는다.

분석 스크립트와 독립 검사의 기준별 판정과 실패 run 목록은 같았다.
