## 이식 메모 (STM32 / 폰)
의사코드 (표본마다, `gyro_rebias.py` 와 같음):
```
on_sample(t, w):
  if t0 unset: t0 = t
  while block_index(t) > k: close_block()          # 0.1 s 블록, 빈 블록도 닫음 (IMU 끊김)
  cur.n += 1; cur.s += w; cur.q += w*w
  b = bias if bias_set else (prov if prov_set else 0)
  return w - b, b

close_block():
  push cur into ring[5]; k += 1; cur = 0
  n = Σring.n; m = Σring.s / n; sd = sqrt(Σring.q / n - m*m)        # 축별
  still = n >= 20 and max(sd) < 0.01 and
          (bias_set ? all |m - bias| < 0.00175 : |m| < 0.0175)
  if still:
     if no segment: open segment with all 5 ring blocks  else add newest block
     (블록 번호 >= 시작 + 20 이면 trim 누적에도 더함)
     if not bias_set and seg_len >= 1.5 s: prov = seg.s / seg.n
  elif segment open:
     L = seg_len; close segment
     if L < (bias_set ? 4.0 : 1.5): return
     cand = (L >= 4.0 ? trim.s / trim.n : seg.s / seg.n)
     if bias_set and any |cand - bias| > 0.00175: reject (gate)
     else bias = cand; bias_set = true
```
- 상태 크기: 링 5 블록 + 현재 블록 = 6 × (n 1 + 합 3 + 제곱합 3) = 42 값, 정지 구간 누적 (전체·trim 각 n + 합 3) 8, 구간 시작·끝 블록 번호 2,
  bias 3 + prov 3, 플래그 2, t0·k 2 → **약 60 개 (float32 와 int32, 약 250 B)**. 표본당 덧셈·곱셈 약 10 번, 0.1 s 마다 창 판정 1 번 (sqrt 3 번).
- float32 주의: 0.1 s 블록 합 (약 50 표본) 은 float32 로 충분. 정지 구간 누적은 최대 수십 초 (수만 표본) → 합은 float32 로 괜찮지만, 아주 긴 정지에 대비해
  누적을 double 로 두거나 블록 평균을 누적 (블록 수로 나눔). 시각은 int64 ns, 블록 번호는 (t − t0) / 100 ms.
- 폰: 센서 콜백 (type 16, `TYPE_GYROSCOPE_UNCALIBRATED` 의 values[0..2]) 에서 바로 호출. STM32: IMU 드라이버 ISR 뒤 메인 루프에서 호출 (sqrt 는 0.1 s 마다만).
