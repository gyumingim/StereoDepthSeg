# 보드 90° 회전 시험 — 사전 등록 (2026-10-22 14:00, VIO·GT 오차를 하나도 계산하기 전에 커밋)

질문: VIO 오차 바닥의 느린 성분(30 s 보다 긴 주기, 약 0.2–0.4 cm, 실행끼리 공통, 보드 y 축을 따름)은
**GT 오차**(보드 자세 편향 → 보드 축에 묶임)인가, **VIO 오차**(중력 = 위아래에 묶임)인가?
(근거: runs/ate_floor_review/judge.md (c)1, docs/ate_floor_20261022.md. 지금까지는 보드 y 와 중력이 3° 안이라 못 갈랐다.)

## 처리 (정해진 것)
- **GT**: imu_learn/overnight_gt.sh, BOARD=auto + LOW_BOARD=config/charuco/board_monitor_6x6.json (마커 0–21 → 모니터 보드), 원본 IMU.
  GT = imu_gt_spl (카메라만, knot 0.0125). 축척 점검 s_fixedlever 보고. 회전 보드에서 검출이 되는지(자세 OK 비율) 보고.
  GT 자세 OK 비율(imu_gt_rs, ok 그리고 |p|<1.2 m) < 0.5 인 녹화는 결과를 보기 전에 뺀다.
- **VIO**: i3-confirm base 설정 그대로 (z2_isolate job 경로 = c5_run → vio_bench_hs.run): --init-cfg strict --init-window 1.0
  --init-disp 15 --clones 11 --noise cfg --imu-lead 2.0 --max-secs 0 --decode-threads 2 --imu-raw, 640x360, 60 fps,
  OpenVINS num_opencv_threads=2, still-hold 끔. **gyro_rebias=False 를 명시적으로 넣는다** (run(a) 의 Namespace 에 a.gyro_rebias=False,
  결과 JSON 의 gyro_rebias 로 확인). 시작 위치 0 / 1 / 2 s (정지 시작 4 s 안). 녹화 3 × 시작 3 = 9 실행.
- 무너진 실행 (전체 ATE > 10 cm 또는 전체 Sim3 축척 0.5–2 밖, 또는 초기화 실패) 은 판정에서 빼고 따로 적는다.
  녹화마다 남은 실행 ≥ 2 개여야 그 녹화를 판정에 쓴다.

## 지표
1. 짝맞춤: imu_learn/ate_floor.match 와 같음 (±2 ms, |p|<1.2 m, VIO 시각 + align_dt_ms, 추적 포즈만).
2. 오차: VIO 전체를 GT 에 **Sim3** (Umeyama) 로 맞춘 뒤 e(t) = GT 보드 좌표의 위치 오차 (축척 몫은 이 질문 밖이라 뺀다).
   SE3 오차로 같은 계산을 한 값도 참고로 적는다 (판정에 안 씀).
3. 느린 성분 (균일 240 Hz 격자에 보간 뒤, 양 끝 edge 패딩, 영위상 이동평균 — ate_floor.lowpass 와 같은 방식):
   - **주 지표 L30** = 30 s 이동평균 (> 30 s 주기 성분)
   - 보조 지표 L5 = 5 s 이동평균 (< 0.2 Hz 성분)
4. 두 좌표계:
   - 보드 좌표 x, y, z (z = 보드 법선)
   - 중력 좌표: u_g = GT 보드 좌표에서 본 중력 방향 = 정규화( 평균_t R_bc(t) · R_ci · a_raw(t) ), 평균은 GT ok 프레임 전체
     (a_raw = 원본 가속도 type 35, IMU 시각 + align dt_ns 로 프레임 시각에 보간, R_ci/dt 는 imu_gt/align.json).
     위아래 = u_g 성분, 수평 = 나머지 2 축.
     점검: scale_ls 가 맞춘 중력 벡터 방향과 비교해 보고. 보드 y 와 u_g 사이 각도를 녹화마다 보고.
5. 몫 (분산 비율, 평균 빼지 않은 제곱합): f_v = Σ(L·u_g)² / Σ|L|², f_y = Σ(L·ŷ_board)² / Σ|L|², 같은 식으로 f_x, f_z.
   등방이면 각 0.33.
6. 녹화 값 = 남은 시작 위치들의 **중앙값**. 비 r = f_y / f_v.
   보조로 "공통 성분" (같은 녹화 시작 위치들의 L30 을 공통 시각에서 평균한 것) 의 f_y, f_v 도 적는다 (판정에 안 씀).

## 판정 규칙 (주 지표 L30, 바꾸지 않음)
- 유효 조건:
  - (a) 회전 녹화 두 개 모두 보드 y 와 u_g 사이 각도가 90° ± 20° 안, 대조 녹화는 0° 또는 180° 에서 15° 안.
  - (b) **대조 (134550) 가 옛 모양을 재현**: f_v ≥ 0.5 그리고 f_v 가 두 수평 축 각각보다 1.5 배 이상 큼
    (옛 녹화 15 개 중앙 0.64, 213341·111836 은 0.61–0.89).
  - 하나라도 어기면 "시험 무효 (미판정)" 이고 이유를 적는다.
- 회전 녹화 **둘 다** r > 1.5 → **"GT 쪽"** (느린 오차가 보드 축을 따라 돌았다)
- 회전 녹화 **둘 다** r < 1/1.5 (= 0.667) → **"VIO 쪽"** (느린 오차가 위아래에 남았다)
- 그 밖 → **"미판정"** (둘이 엇갈리거나 비가 1.5 배 안).
- 크기 주의: 회전 녹화의 L30 RMS 가 0.1 cm 미만이면 결론에 "느린 성분이 작아 근거 약함" 을 붙인다. L5 (보조) 결과가 주 지표와
  반대면 그 사실을 결론에 적는다 (판정은 주 지표대로).

## 섞인 변수 (미리 적어 둠)
- 회전 녹화에서 사람이 폰을 드는 방식(폰 축 대 중력)과 보드에 대한 움직임 방향이 대조와 다를 수 있다. 그래서 축별 GT 움직임 크기
  (보드 좌표·중력 좌표의 위치 표준편차)를 함께 보고한다. 오차가 "움직임이 큰 축"을 따른 것이면 결론에 적는다 (추정).
