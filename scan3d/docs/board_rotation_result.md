## 결론 (먼저)
- **사전 등록 판정: "시험 무효 (미판정)".** 회전 녹화 133820 의 VIO 3 실행이 **모두 무너져** (전체 축척 0.04–0.05, ATE 280–386 cm)
  "회전 녹화 둘 다" 조건을 채우지 못했다.
- 남은 회전 녹화 134204 (**녹화 1 개**, 거리 0.66 m) 에서 말할 수 있는 것: **큰 위아래 느린 오차 (L30 0.50–0.64 cm) 는 보드를 돌려도 위아래에 남았다.**
  그래서 "느린 오차 전체 (약 0.6 cm) 가 보드 y 에 묶인 GT 편향" 이라는 가설은 약해졌다 (경향, 녹화 1 개).
- 그러나 **0.2–0.4 cm 크기의 보드 축 GT 편향은 배제 못 한다.** 134204 의 보드 y L30 RMS 가 실행별 **0.40 / 0.10 / 0.17 cm** 남아 있다.

  **보드 y 0.3 cm 편향을 넣어도 r 은 0.667 을 넘지 않았다** → r 규칙으로는 이 질문에 답할 수 없다.
- "VIO 쪽" 이라고도 못 쓴다: 카메라 축이 중력과 같이 움직여 (두 녹화 모두 폰 가로), 카메라 축에 묶인 GT 오차 (롤링셔터, fy, OIS 처짐) 와 VIO 오차를 못 나눈다.
- **대조 134550 은 사전 조건 (b) 를 통과** (위아래 = 보드 y 몫 0.76 / 0.74, 수평 0.03·0.22). 단 유효 실행 2 개, o0 은 1.56 배로 겨우 통과, L30 RMS 0.74 cm 로 옛 바닥 (0.2–0.4 cm) 의 약 2 배라 "옛 현상을 재현" 의 의미는 약하다.

## 주의 (섞인 변수 · 한계)
1. **녹화 1 개만 유효** (133820 VIO 무너짐). 같은 녹화의 시작 위치 3 개는 독립이 아니다. 60 s 자료에 30 s 창이라 독립 표본은 약 2 개 (추정).
2. **움직임이 큰 축 = 위아래**: GT 위치 표준편차 134204 위아래 12.6 cm / 보드 y 4.8 / 법선 9.4; 대조 위아래 11.4 / 보드 x 4.7 / 법선 5.0.
   위치에 비례하는 보드 축 GT 오차라면 보드 y 로 4.8 cm 만 움직인 134204 에서 작게 보일 수밖에 없다. 반론: 법선 9.4 cm 움직임에도 0.04–0.08 cm 라 크기만으로 다 설명되지는 않는다 (추정).
3. **카메라 축은 안 돌았다**: 시작 정지 때 카메라 좌표의 중력은 세 녹화 모두 (0.015, −0.94, 0.30–0.35) 로 같다. 이 시험이 배제할 수 있는 것은 **보드 축에 묶인** GT 오차뿐이고,
   카메라 축에 묶인 GT 오차 (롤링셔터 행 방향, fy, OIS·AF 처짐) 는 여전히 후보다.
4. **거리·시선각도 섞였다**: 카메라–보드 거리 중앙값 133820 **0.68 m**, 134204 **0.66 m**, 대조 134550 **0.58 m**. 회전 녹화 **둘 다** 계획한 40–60 cm 밖이고 대조보다 14–17 % 멀다
   (처음 문서의 "133820 만 멂" 은 틀림). 시선각 중앙값 134204 10.1°, 대조 6.4°. 모니터 기울기도 7.2 / 3.6 / 2.0° 로 녹화마다 다름 (영향 작음, 추정).
5. 133820 무너짐 원인 (후속 조사, docs/board_rotation_collapse_133820.md): 손 움직임 중간 약 35–41 s 에 폰을 거의 멈춘 동안 ZUPT 가 이어지다가
   SLAM 특징이 한꺼번에 0 이 되고 MSCKF 도 0 → 다시 움직이자 영상 갱신 없이 IMU 적분만 → 수 m 발산. **VIO 실패**이며 보드 회전·거리 탓이 아니다. 대조 134550 o2 도 같은 방식으로 무너졌다.
6. 계획 대비 바뀐 점: 계획의 "scale_ls 가 맞춘 중력 방향과 비교" 는 scale_ls JSON 에 |g| 만 있어 할 수 없었고, 대신 **시작 정지만으로 구한 중력 방향** 과 비교했다 (0.4–0.6°).
7. VIO 설정: i3-confirm base, gyro_rebias=False 를 명시 (실행 JSON gyro_rebias = False 9/9 확인), 코드 blob 8e9af4e (board_rotation.py), git 7b9f31a.
