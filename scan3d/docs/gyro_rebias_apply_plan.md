# 자이로 정지마다 재보정 — 표준 전처리 적용 전 안전 검사 (사전 등록)

만든 때 2026-10-22, 계산 전에 커밋. 사용자 결정: `docs/imu_calib_gain.md` 의 D (정지마다 바이어스 다시 잡기) 를 IMU 표준 전처리로 넣음
(VIO 를 해치지 않았고, 카메라 추적이 끊겨 자이로만으로 버틸 때 이득). 넣기 전에 알려진 실패 (222747: 느린 회전을 정지로 잡아 D 3.40 vs C 1.27 deg) 를 고친
스트리밍 모듈 `imu_learn/gyro_rebias.py` 가 아래 기준을 통과해야 기본값 제안.

## 모듈 (G) — `imu_learn/gyro_rebias.py` (이 커밋)
- 입력 raw type 16 (v0..2) 한 표본씩, 출력 = 보정 자이로 + 현재 바이어스. 과거 표본만 씀.
- 0.1 s 블록 (n, 합, 제곱합) → 0.5 s 창 (0.1 s 마다). 정지 창 = 표본 ≥ 20, 축별 std < 0.01 rad/s (573 mdeg/s), 그리고
  바이어스 없을 때 |평균| < 1000 mdeg/s (옛 1700), 있을 때 축별 |평균 − 바이어스| < 100 mdeg/s.
- 연속 정지 창 = 정지 구간. 첫 바이어스: 시작 정지가 1.5 s 넘으면 블록마다 누적 평균을 임시 바이어스로, 끝나면 확정.
- 이후 갱신: 4 s 이상 정지가 끝날 때, 앞 2 s 뺀 평균. 게이트: 어느 축이든 현재 값과 100 mdeg/s 넘게 다르면 버림.
- **임계값을 정한 과정 (공개)**: std·평균 임계는 같은 8 개 녹화의 정지 창 통계 (참 정지 std 최대 502 mdeg/s, 바이어스 노름 약 400) 를 보고 정함.
  "갱신은 4 s 이상 정지만" 은 모듈이 같은 녹화에서 고른 정지 구간 목록 (GT 오차는 계산 안 함) 을 보고 넣음 — 1.6–2.6 s 짧은 정지가
  느린 회전 (222747 y 159, 215348 y 212, 224323 여러 개) 이었기 때문. 따라서 Part 1 은 **같은 데이터로 고른 규칙의 확인**이지 독립 시험이 아님 (일반화 미확인).
  계산 전 확인된 정지 목록: 10-21 3 개 녹화 = D 와 같은 정지 (215348 은 141.6 s 이후 짧은 두 정지 제외), 10-20 5 개 = 시작 정지만 (= C).

## (a) Part 1 — 자이로만 적분 회전 오차 (`calib_gain.py` 와 같은 창·채점)
- 녹화 8 개 (`calib_gain.md` 와 같음), 10 s 창, 시작 = 첫 `still_runs` 정지 끝 이후 GT 유효 프레임 전부. G 바이어스는 모듈을 녹화 처음부터 돌린 값 (인과적).
- 비교 조건 B (type 4), C (시작 정지만), D, D2 를 같은 코드로 다시 계산 (`imu_learn/gyro_rebias_eval.py`).
- **통과 기준**: (1) 모든 녹화에서 G 중앙값 ≤ 1.10 × C 중앙값, **그리고** (2) 녹화별 중앙값의 중앙값이 G < B.
- 보고: 녹화별 중앙값·p90, 요 드리프트율 (deg/분).

## (b) Part 2 — OpenVINS 벤치 (`calib_gain_p2.py` 와 같은 9 쌍)
- 213341 / 214550 / 215348 × 시작 0/1/2 s (`runs/i3_confirm/inputs`), i3 confirm base 설정 (`z2_regress.common(rec, off, 2.0, 0, True)`,
  `num_opencv_threads=2`, still-hold 없음, `--imu-raw`). 조건 U = 그대로, G = `--gyro-rebias` (벤치 안에서 모듈 적용). 둘 다 새로 실행 (18 런, 동시 ≤ 5).
- **통과 기준**: (1) 쌍별 ATE 차 (G − U) 의 중앙값 ≤ +0.1 cm, **그리고** (2) 새 붕괴 없음 = U 가 ok 인데 G 가 ok 아닌 쌍 0 개
  (ok 규칙 = Part 2 와 같음: 초기화됨, 점수 있음, 붕괴 표시 없음, scale 0.5–2, ATE ≤ 10 cm).
- 보고: ATE 중앙값 U/G, 승패 수, VIO 요 드리프트 (Part 2 와 같은 식).
- **자이로만 지표 (보고, 판정 안 씀)**: 자이로만 적분 요 드리프트율 (deg/분) = Part 1 의 yaw 지표, 녹화별 B / C / G (8 개 전부, 벤치 녹화 3 개 따로 표시).
