## 결론 (먼저)

**A2 도 채택하지 않는다. 기준 1·2·3 실패, 4 통과.** 분석과 독립 검사의 기준별 판정과 실패 run 목록이 같았다. 그래도 네 후보 중 결과가 가장 좋다.

- **표적은 막았다.**
  - 133820: 280–386 → 1.6–4.0 cm. 134550 o2: 18.5 → 0.76 cm. 전멸 6 → 0.
  - 기준 1 이 실패한 이유는 133820 각 run 에 "전부 거절 갱신" 이 1 회씩 남은 것 하나뿐이다. A·A' 와 같은 시각(50.9–52.7 s, 움직이는 중)이다.
- **A·A' 의 쪼개짐은 대부분 사라졌다.**
  - 154320 o0 붕괴가 없어졌다: A·A' 는 501 cm, A2 는 2.33 cm (base 11.1).
  - 222747 3 run 은 계속 살렸다 (121–6842 → 0.9–1.0 cm).
- **남은 회귀.**
  - 213955 o1: 12.3 → 18 293 cm. A·A' 에서도 붕괴했다. 시작 정지는 base 와 같고 (첫 추적 75/75 같음), 12.9 s 전멸 뒤 base 는 회복했지만 A2 는 회복하지 못했다.
  - 214550 o1: ATE 18.29 → 23.14 cm (한계 20.12). 1 s 상대 오차도 4.09 → 4.71 cm 로 조금 나빠졌다.
  - 나머지 기준 2 실패 3 건(154320 o0/o2, 214138 o1)은 ATE 가 base 와 같거나 더 좋은 run 의 새 전멸이다 (아래 표).
