## 결론 (먼저)

**C 도 채택하지 않는다. 기준 1·2 실패, 3·4 통과.** 판정 규칙대로 하면 다음은 기전 재조사이고, D 는 그 뒤다.

- **표적 133820 을 못 막았다.** ATE 280–386 → 389–444 cm (A 는 1.2–4.7 cm).
  - 정의상 "전부 거절 갱신"과 "SLAM 전멸"은 0 회다.
  - 그러나 SLAM 은 여전히 다 죽었다. 0.3 s 마다 강제한 일반 갱신 세 번에서 75 % → 87 % → 100 % 가 거절되고, 0.7 s 동안 44 → 0 개가 됐다.
  - 0.2 s 안에 떨어져야 전멸로 세는 정의가 이 느린 감소를 못 잡았을 뿐이다.
- 134550 o2 는 살렸다 (18.5 → 0.8 cm). 222747 은 일부만 살렸다 (156 / 121 / 6842 → 35 / 38 / 7289 cm).
- **부작용은 A 보다 훨씬 작다.**
  - 시작 정지 면제가 동작했다. 첫 추적 포즈 시각이 75 칸 모두 base 와 같다.
  - 134204 ATE 는 base 와 같다.
  - 214550 ATE 는 base 와 0.1 cm 안이다 (A 에서 실패한 o1 도 18.29 → 18.31).
  - 154320 o0 는 붕괴하지 않았다 (11.1 → 2.1 cm, A 는 501 cm).
- 해석 (추정): 문제는 ZUPT 연속이 "긴" 것이 아니다. 실제로 움직이는 동안 ZUPT 가 "수락되는" 것 자체다. 0.3 s 의 위치 고정만으로도 133820 의 느린 움직임에서는 SLAM 이 무너진다. A 처럼 수락 판정을 고치는 쪽이 효과가 있다.
