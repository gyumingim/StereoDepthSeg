## 4. 요약
- 감사와 다른 판정: **A1 OIS(틀림: 문서가 OIS를 허용 키로 명시하고 데이터에도 OIS 흔적 없음)**, A8 EIS(과장), A9 skew 상수(과장), A3 위험도(버그는 맞지만 영향 ≤0.5 mm 추정), A5의 "CNN은 못 고침"(과장).
